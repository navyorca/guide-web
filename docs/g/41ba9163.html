Overview

이 과정은 무엇인가

코딩을 몰라도 Claude Code와 대화하며 실습으로 배우고, 90시간 동안 기획부터 배포까지 직접 완주하는 과정입니다.

핵심
문법을 먼저 배우지 않습니다. 실습하며 필요한 개념을 그때그때 익히고, 마지막엔 본인 서비스 하나를 실제 URL로 완성합니다.

Principle

모듈 B 학습 원리

선행 문법이 아니라 '만들면서 배우는' 순환 구조

선수과목 없음
피그마 수강 여부와 무관하게 누구나 바로 시작할 수 있습니다
실습 중심 진행
개념 설명은 짧게, 직접 만들어보는 실습과 피드백에 대부분의 시간을 씁니다
범위는 기획부터 배포까지
기획·화면 제작·데이터 연동·배포까지 다루고, 마케팅·판매는 다루지 않습니다
