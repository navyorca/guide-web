AIPOT_1급_대비책

#에이아이팟 #AI자격증 #프롬프트엔지니어링자격증 #시험대비 #한국생산성본부

AIPOT 1급(생성형 AI프롬프트 엔지니어링) 취득 대비책. A형·B형 공식 샘플문제와 사용가이드 v09 분석 기준. 작성일 2026-06-30.

시험 구조 (샘플 기준)

40문항, 60분. A형·B형 동형 구조이며 블록별 배치가 동일하다.

  • 1~23번: 객관식 4지선다 + 일부 단답. 인공지능·생성형 AI 이론.
  • 24~30번: 단답형([단답]). 용어·기법명을 정확한 표기로 적는다.
  • 31~35번: 도구 실습 매칭/빈칸. A형은 SORA(영상), B형은 ComfyUI(이미지) 사용.
  • 36~40번: 서술형. 실제 프롬프트를 작성해 제출. 배점·변별력 최상.

득점 전략: 1~30번은 개념 암기로 확보, 36~40번 서술형은 패턴 공식으로 만점을 노린다. 31~35번은 도구별 노드·메뉴 명칭 암기가 관건.

시험 운영 규칙 (가이드 v09, 반드시 숙지)

  • 단일 턴(Single turn). 한 번의 프롬프트로 결과를 내야 하며 대화 이어가기로 보정 불가.
  • 파일 첨부 가능 형식은 txt, jpg, png 세 가지뿐.
  • 입력 글자수 제한: 영문 약 3,000자, 한글 약 1,024자.
  • 서술형 답안 분량 권장 10~15줄.
  • 코드·결과는 지정된 구분기호(따옴표, 백틱, 꺾쇠 등) 형식을 그대로 지켜 출력하도록 지시해야 함.

출제 영역별 핵심 (빈출 순)

인공지능 이론

  • 머신러닝·딥러닝·지도학습 위계와 정의 구분.
  • 혼동행렬(Confusion Matrix): 정확도·정밀도·재현율·F1 계산. F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율).
  • 경사하강법·역전파·학습률·활성화함수의 역할 구분.
  • 과적합(Overfitting)·과소적합(Underfitting)·결측치(Missing Value) 개념.
  • 가지치기(Pruning), K-Fold 교차검증, 시그모이드 함수.
  • 프레임워크: TensorFlow(텐서·그래프·세션), PyTorch(Pythonic), XGBoost, Spark MLlib.

생성형 AI 이론

  • 트랜스포머·어텐션(2017, 자연어처리 기반), GAN(생성자 대 판별자), VAE.
  • GPT·BERT, 사전학습(Pre-trained)과 파인튜닝(Fine-tuning) 차이.
  • LLM·파운데이션 모델, 멀티모달, AI에이전트, 온디바이스 AI, AGI.
  • LangChain, RAG(검색증강생성)의 구성·동작 원리.
  • 에이전트 구성요소: 입력·LLM·도구(API·DB)·루프(Loop)·출력.

프롬프트 엔지니어링 기법(단답·서술 모두 빈출)

  • Zero-shot / Few-shot Learning, Fine-tuning 구분.
  • CoT(Chain of Thought), Zero-shot CoT("Let's think step by step").
  • Self-refine(자기개선), Complexity-based, Generated-knowledge 프롬프팅.
  • 구분기호 용도: 큰따옴표·작은따옴표·백틱(```)·꺾쇠(<>)·달러($$)·중괄호({}).
  • 마크다운 출력 지시: 굵게(**), 헤더(##), 표, 목록.
  • 디코딩 파라미터: Beam Width, Top-p, Temperature.

도구 활용

  • ChatGPT for Excel: AI.TABLE, AI.EXTRACT, AI.CHOICE, AI.TRANSLATE 기능 구분.
  • ChatGPT for PowerPoint: Create from Text / Topic / YouTube / File 구분.
  • 데이터 분석: EDA(탐색적 데이터분석), PCA(주성분분석), CSV 통계 해석.
  • SORA(A형): txt2vid·img2vid·vid2vid, Re-cut·Remix·Blend·Loop, 해상도(1080p FHD / 720p HD / 480p SD), 화면비 계산.
  • ComfyUI(B형): Empty Latent Image(Width·Height), KSampler(Steps·cfg·Seed), VAE 노드 명칭.

윤리·리스크

  • 4대 원칙: 공정성(Fairness)·투명성(Transparency)·책임성(Accountability)·안전성(Safety).
  • 환각(Hallucination), 편향(Bias), 저작권, 딥페이크, 워터마크(Watermark).

서술형(36~40) 답안 공식

이 블록은 패턴이 고정되어 있다. 샘플 5유형을 그대로 익히면 응용 가능하다.

이미지 분석 후 영문 프롬프트 작성형(A형 37번)

업로드 이미지를 묘사하는 영문 한 문장. 필수 요소를 빠짐없이 나열한다. 예시 구조: "Create a black and white, 1:1 square ratio image of [주체] [행동], with [부속 요소], and [배경 요소]." 색상·화면비·주요 사물·배경을 모두 포함해야 감점이 없다.

JSON 출력 지시형(A형 39번)

첨부 txt를 읽어 조건을 모두 만족하는 JSON을 출력하라고 명시. 필수 지시 사항: key 구성 고정, 숫자형은 쉼표 없이, 문자열 처리 항목 구분, 정보 없는 항목은 반드시 null로 출력. "텍스트 기반으로 모든 조건을 충족하는 JSON만 출력"을 못 박는다.

이미지 키워드 추출형(A형 40번)

응답 포맷을 그대로 제시하고 빈칸만 채우게 한다. "영어 : {1}, {2}, {3}" / "한글 : {1}, {2}, {3}" 형식 유지.

텍스트 핵심정보 추출형(B형 39번)

첨부 txt에서 고유명사·수치를 지정 형식으로 추출. 숫자 단위·연도를 누락 없이.

표·다항목 구조화형(B형 40번, A형 38번)

여러 항목을 ### 헤더 + - 속성: 값 구조나 정렬된 목록으로 출력하도록 지시. 정렬 기준(오름차순 등)을 명시.

학습 우선순위

1순위(득점 직결): 서술형 5패턴 공식 + 구분기호·마크다운 출력 규칙 + JSON/null 처리.

2순위(개념 확보): 프롬프트 기법명 정확한 표기, 혼동행렬 계산, 트랜스포머·RAG·파인튜닝.

3순위(도구 암기): 응시 회차 도구(SORA 또는 ComfyUI) 노드·메뉴 명칭, Excel/PPT 함수 구분.

4순위(마무리): 윤리 4원칙, 환각·워터마크 등 리스크 용어.

권장 일정 (집중 학습 시)

  • 1~2일차: A형·B형 샘플 40문항씩 정답 가린 채 풀고 오답 정리.
  • 3일차: 서술형 36~40번 5패턴을 직접 손으로 3회 이상 재작성.
  • 4일차: 응시 도구(SORA/ComfyUI) 실습 또는 노드 명칭 암기, Excel·PPT 함수 정리.
  • 5일차: 단답 용어 50개 플래시카드 암기, 윤리·리스크 마무리.
  • 직전: 시험 운영 규칙(단일 턴·글자수·파일형식) 재확인, 샘플 재풀이로 시간 배분 점검.
