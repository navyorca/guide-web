지난 두 번 수업 따라잡기

10월 23일·30일 금요일 프롬프트 수업(1~4일차)에서 다룬 내용입니다. 하루 10분씩, 휴대폰이나 PC로 따라 하시면 11월 6일 수업을 바로 따라가실 수 있습니다.

1일차

ChatGPT를 내 스타일로 맞추기

ChatGPT 왼쪽 아래 내 이름 → 설정 → 개인 맞춤 설정에 아래처럼 적습니다.

나는 온라인 마케팅을 배우는 수강생이야.
답은 쉬운 말로, 3줄 요약을 먼저 쓰고 그다음에 자세히 써 줘.
모르는 내용은 지어내지 말고 모른다고 말해 줘.

환각현상은 AI가 그럴듯하게 틀린 말을 하는 것입니다. 숫자·날짜·법 내용은 "출처도 같이 알려 줘"라고 덧붙이고, 중요한 값은 직접 한 번 더 확인합니다.

새 채팅에서 "안녕"이라고 쳤을 때 3줄 요약 형식으로 답하면 성공입니다.

2일차

NotebookLM으로 자료 정리하기

notebooklm.google.com → 구글 로그인 → 새 노트북 → 자료(PDF·웹 링크·글)를 넣습니다.

  • 넣은 자료 안에서만 답해 주기 때문에 지어내는 답이 적습니다.
  • 오른쪽 스튜디오에서 보고서·인포그래픽·슬라이드를 바로 만들 수 있습니다.

관심 있는 기사 링크 하나를 넣고 "세 줄로 요약해 줘"를 쳐 보시면 됩니다.

3일차

자료 조사 → 발표자료 만들기

  • Perplexity: 질문하면 답과 함께 출처 링크를 보여 주는 검색 AI입니다.
  • Gamma: 주제만 넣으면 슬라이드 초안을 자동으로 만듭니다.
  • Canva: 만든 슬라이드의 글꼴·색·사진을 다듬습니다.

순서는 조사(Perplexity) → 초안(Gamma) → 다듬기(Canva)입니다.

4일차

GPTs, 나만의 챗봇 만들기

ChatGPT 왼쪽 GPT 탐색 → 만들기 → 이 챗봇이 할 일을 적습니다. 만들기는 유료(Plus) 요금제에서 됩니다.

너는 엑셀 함수 도우미야.
내가 하고 싶은 일을 말하면 쓸 함수와 예시를 한 줄씩 알려 줘.

한 번 만들어 두면 같은 설명을 매번 다시 쓰지 않아도 됩니다.

좋은 질문 공식, 이것 하나만

역할 → 상황 → 할 일 → 형식 순서로 쓰면 답이 확 좋아집니다. 이 공식이 프롬프트 수업 전체의 뼈대이고, 에이전트 수업도 이 위에서 시작합니다.

[역할] 너는 온라인 쇼핑몰 마케터야.
[상황] 30~40대 직장인에게 텀블러를 팔려고 해.
[할 일] 상세페이지 첫 문장 후보를 만들어 줘.
[형식] 5개를 표로, 옆에 노린 점을 한 줄씩 써 줘.

오늘 숙제 하나: 위 공식에 내 상품이나 관심사를 넣어 ChatGPT에 한 번 물어보고, 마음에 든 답을 캡처해 멘토에게 보내 주세요.
