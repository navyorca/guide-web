#원패스 #바우처 #타계열할인 #오십만원할인권

KEG ONE PASS 한 장 요약

핵심: 신규 등록생에게 주는 타 계열 전용 50만원 할인권입니다. 상담 클로징 무기예요.

  1. 발급 (우리 지점 신규 등록생에게 지급)

결제 금액별 자동 지급: 100만원↑ = 1매 / 200만원↑ = 2매 / 300만원↑ = 3매 (인당 최대 3매)

100만원 미만은 지급 대상 아님

최초 등록 당일 계약 기준. 추가 결제·분할 잔금은 합산 안 됨 (→ "묶어서 등록해야 최대 3장" 업셀링 무기로 활용)

가족·형제라도 금액 합산 불가, 개인별 계약으로만 산정

  1. 사용 (고객이 할인권 들고 왔을 때)

1매 = 50만원 즉시 할인

반드시 실물 지류 수령 (캡처·분실 시 적용 불가, 예외 없음)

같은 계열은 사용 불가 → 타 계열 신규 등록 시에만

예외: 지인에게 양도한 경우 '지인 사용' 체크하면 동일 계열도 가능

★★★1과목 = 1매만 (중복 적용 불가 → 2장 쓰려면 2과목 등록 유도)★★★

제3자 양도 자유 (인적 관계 증명 불필요)

정규과정만 적용. 특강·원데이·교재비 불가, 국비·타 할인과 중복 불가, 현금 환불 불가

  1. 유효기간·유실

발급일로부터 1년, 만료 시 자동 소멸

지류 분실 시 [유실] 탭에서 즉시 유실 처리

  1. 환불 시 (분쟁 방지 → 반드시 사전 고지)

① 할인권 회수: 부분취소로 금액 구간 하락 시 초과분 실물 반납. 못 하면 1매당 50만원 차감

② 할인율 재산정: 과목 수 줄면 패키지 할인율도 축소 소급 적용

사용해서 등록한 과정을 취소해도 제출한 할인권은 반환 안 됨(소멸)
