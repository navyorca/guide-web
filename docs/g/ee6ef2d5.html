스킬

슬래시 명령어 직접 만들기

자주 쓰는 지시를 슬래시 명령 하나로 줄여 반복 없이 부를 수 있다.

스킬 정의파일 하나가 슬래시 명령어 하나
  • 자주 시키는 일을 한 줄 명령으로 축약이 목적
파일 위치프로젝트 전용 · 컴퓨터 전체 전용 구분
  • .claude/skills/<이름>/SKILL.md에 두면 그 프로젝트 폴더에서만 쓴다
  • ~/.claude/skills/<이름>/SKILL.md에 두면 이 컴퓨터의 모든 프로젝트에서 쓴다
호출 방법직접 호출 · 자동 호출 2가지
  • /스킬이름 직접 호출, /스킬이름 [인수] 값 전달
  • 관련 대화가 등장하면 클로드가 자동으로 호출하며, 판단 기준은 description이다
SKILL.md 구조머리말 description + 지침 본문
  • 위 세 줄은 머리말이고, description 한 줄에 스킬이 하는 일을 적는다
---
description: 이 Skill이 하는 일
---
# 지침
클로드에게 줄 지시사항을 마크다운으로 작성
  • 아래 본문은 업무 지시서 형식의 마크다운으로 쓴다
  • 기본 제공 스킬 예시로 /simplify /batch /debug /loop가 있다
description 예시실제 말할 낱말을 넣어야 자동 발동
  • 회의록 정리 스킬 → description에 "회의록·미팅 메모를 안건·결정·할 일로 정리" 기재
  • "어제 회의 메모 정리해줘"만으로도 클로드가 이 스킬 사용

요약 스킬은 반복 지시를 한 줄로 축약하며, 저장 위치는 프로젝트·전체 2단계로, 호출은 직접·자동 2가지로 나뉘고 자동 호출 여부는 description이 판단한다.

재료 고르기

라이브러리와 Pillow

라이브러리를 설치해 두면 코드 한 줄로 완성된 기능을 바로 가져다 쓴다.

라이브러리남이 만든 기능 모음
  • 표준 라이브러리(os · shutil · zipfile)는 Python 기본 내장, 설치 불필요
pip(Python)Python 라이브러리 설치 명령
pip install pillow
pip install qrcode
pip install requests
  • 순서대로 이미지 처리 · QR 코드 생성 · 인터넷 요청
npm(Node.js)Node.js 라이브러리 설치 명령
npm install sharp
npm install qrcode
npm install axios
  • Python 라이브러리와 같은 역할의 Node.js 버전
PillowPython 이미지 라이브러리
  • 설치 pip install pillow
  • 만들기 Image.new() 캔버스, ImageDraw 도형·글자, ImageFont 글꼴
  • 고치기 resize() 크기 변환, crop() 잘라내기, save() PNG·JPG 저장
  • 카드뉴스는 1080x1080 캔버스에 배경색·글자색·글꼴을 지정하고 리사이즈로 여러 크기를 만든다

요약 라이브러리는 한 번만 설치하면 많은 기능을 한꺼번에 확보하며, 오늘 쓴 Pillow는 Image.new·ImageDraw·resize·save 네 함수만으로 카드뉴스 제작을 끝낸다.

실습

카드뉴스 실습 3단계

한 번 만든 카드뉴스를 스킬로 저장해 두면 다음부터는 한 줄로 다시 만든다.

01카드뉴스 요청구체적 사양을 문장으로 전달
pillow로 1080x1080 카드뉴스 이미지 만들어줘.
배경 남색, 제목 "AI가 바꾸는 세상" 흰색 굵게 중앙,
본문 "2줄 설명" 회색 작게, 하단 로고 영역 포함
  • 클로드가 pip 설치 · cardnews.py 작성 · 실행 · output.png 확인까지 처리
02스킬로 전환반복 요청을 스킬 파일로 고정
방금 만든 카드뉴스 코드를 /cardnews 스킬로 만들어줘.
배경색, 글자색, 제목, 본문, 사이즈를 인수로 받도록 해줘
  • 생성 파일 2개: .claude/skills/cardnews/SKILL.md(지침·옵션 목록), cardnews.py(그리는 코드)
03한 줄 반복/cardnews + 옵션값
/cardnews 배경=남색 제목="AI가 바꾸는 세상" 본문="두 줄 설명 텍스트"
/cardnews 배경=흰색 글자=검정 제목="오늘의 뉴스" 사이즈=1080x1350
/cardnews 배경=#FF6B35 제목="SALE 50%" 리사이즈=썸네일
  • 세 번째 줄은 1080x1080 원본과 360x360 썸네일을 동시에 저장한다
  • 옵션으로 배경·글자·강조색, 제목·부제·본문 글자 크기, 정렬, 사이즈, 리사이즈를 받는다

요약 스킬의 핵심은 반복 작업을 한 줄 명령으로 바꿔 재사용 가능한 자동화를 만드는 데 있다.

응용

나만의 스킬 작업 순서

원하는 기능만 말하면 라이브러리 선택부터 스킬 완성까지 클로드가 대신 진행한다.

세 단계기능 말하기 → 조사·코드 요청 → 스킬화 요청
  • 1 원하는 기능 말하기 → 2 라이브러리 조사와 코드 요청 → 3 스킬로 만들어 달라고 하기
  • 예 "QR 코드 만들고 싶어" → "Python으로 만들려면 어떤 라이브러리 써? 코드까지 작성해줘" → "이걸 /qrcode 스킬로 만들어줘. 옵션을 인수로 받게"
대응표원하는 것 · 라이브러리 · 스킬 명령어
스킬 명령어 대응표
원하는 것라이브러리스킬 명령어
QR 코드 생성pip install qrcode/qrcode [텍스트]
이미지 워터마크pip install pillow/watermark [이미지]
파일 자동 압축·백업zipfile(표준 내장)/backup [폴더]
마크다운 → HTMLpip install markdown/md2html [파일]
응용 예시반복 업무를 스킬로 우선 제작
  • 동아리 홍보 담당 → 날짜·장소만 바꾸는 /poster 스킬
  • 작은 가게 → 오늘 메뉴 카드뉴스 /menu 스킬
  • 매주 반복하는 일을 먼저 스킬로 제작

요약 기능 말하기·조사와 코드 요청·스킬화 요청 세 단계를 따르면, 원하는 기능이 라이브러리를 거쳐 명령어로 이어지는 흐름을 대응표 4개 예시로 확인할 수 있다.

설치해서 쓰는 것

플러그인이란

직접 만들지 않아도 남이 만든 스킬·명령어·훅을 통째로 설치해 쓸 수 있다.

플러그인 정의스킬은 내가 만드는 것, 플러그인은 설치해서 쓰는 것
  • 한 번 설치로 여러 기능 동시 적용
  • 팀·커뮤니티 공유, 버전 관리, 여러 프로젝트 재사용
단독 설정(.claude/)개인·프로젝트 전용, 빠른 실험
  • /hello처럼 짧은 이름으로 호출
플러그인 호출공유·배포·버전 관리에 대응
  • /plugin-name:hello처럼 이름을 앞에 붙여 호출
  • 네임스페이스 = 콜론 앞 플러그인 이름. 같은 이름 스킬의 충돌 방지
폴더 구조5개 구성 요소
.claude-plugin/plugin.json   이름 · 설명 · 버전 (이 파일만 이 폴더 안)
skills/                      스킬
commands/                    명령어
agents/                      에이전트
hooks/                       훅
.mcp.json                    MCP 서버 설정

요약 플러그인은 스킬·명령어·에이전트·훅·MCP 다섯 요소를 묶은 것이며, 콜론이 붙은 호출 방식으로 단독 설정과 구분된다.

마켓플레이스 3단계

마켓플레이스와 설치·관리

쓰고 싶은 플러그인을 목록에 등록한 뒤 골라서 설치하고, 필요 없으면 끄거나 지운다.

마켓플레이스 종류공식 · 커뮤니티 2가지
  • 공식 claude-plugins-official = 기본 제공, 추가 단계 생략, 바로 사용
  • 커뮤니티 claude-community = 심사 통과 서드파티 모음
01마켓플레이스 추가목록 등록. 설치는 다음 단계
/plugin marketplace add anthropics/claude-plugins-community
/plugin marketplace list
  • GitHub 저장소 외 Git 주소 · 내 컴퓨터 폴더 · marketplace.json 주소도 등록 가능
02플러그인 설치/plugin 화면은 탭 4개
/plugin install github@claude-plugins-official
/reload-plugins
  • /plugin 단독 실행 시 Discover · Installed · Marketplaces · Errors 탭 표시
  • 설치 범위 3가지 User(전체) · Project(저장소 공유) · Local(나만)
  • /reload-plugins를 실행하면 재시작 없이 바로 적용된다
03관리목록·끄기·켜기·삭제·최신화
/plugin list
/plugin disable <이름>@<마켓>
/plugin enable <이름>@<마켓>
/plugin uninstall <이름>@<마켓>
/plugin marketplace update <마켓>
  • 순서대로 목록 보기 · 끄기 · 켜기 · 완전 삭제 · 목록 최신화
  • 변경 후 /reload-plugins 필수
공식 마켓 대표 플러그인용도별 분류
  • 외부 연동(MCP 묶음) github · gitlab · slack · notion · figma · sentry
  • 개발 흐름 commit-commands · pr-review-toolkit · plugin-dev
  • 코드 도우미·보안 pyright-lsp · typescript-lsp · security-guidance
  • 설치 전 Discover 탭에서 추가 내용·문맥 사용량 확인 가능

요약 마켓플레이스는 추가·설치·관리 3단계로 진행하며, 무엇을 바꾸든 마지막엔 항상 /reload-plugins를 실행한다.

7회차 마무리

플러그인 설치 실습

공식 마켓에서 플러그인 하나를 직접 설치해 보면 앞 절 과정이 손에 붙는다.

설치·실행commit-commands 예시
/plugin install commit-commands@claude-plugins-official
/reload-plugins
/commit-commands:commit
  • /plugin Discover 탭에서 골라 설치해도 동일
  • 설치한 플러그인의 스킬은 항상 플러그인이름:스킬 형식으로 호출한다
실습 전 준비Git 저장소 필수
  • commit은 Git 저장소 안에서만 동작
  • 실습 폴더에서 git init 먼저 실행, 또는 클로드에게 "이 폴더를 git 저장소로 만들어줘" 요청

요약 commit-commands는 install·reload·호출 3단계로 설치하며, 그 전에 git 저장소가 먼저 있어야 한다.

8회차 본론

클로드 데스크톱 세 가지

데스크톱 앱 안에서도 채팅·Code·Cowork 세 자리는 하는 일이 서로 다르다.

01일반 Claude Desktop대화형 채팅
  • 대화형 채팅과 파일 첨부·분석
  • Projects로 복잡한 작업을 프로젝트 단위 관리
  • MCP 서버 연동, 커스텀 스킬 등록 가능
  • claude.ai/downloads에서 macOS·Windows 설치, claude.ai 계정 로그인, 유료 플랜 권장
02Desktop Claude Code앱 안 Code 탭
  • Code 탭 클릭으로 시작
  • claude --resume으로 터미널(CLI)과 데스크톱 대화 이력 연결. CLI → 데스크톱 → 웹 자유 이동
  • /ide 명령으로 VS Code 연결, 화면에서 파일 수정
03Claude Cowork폴더 지정 → 직접 작업
  • Cowork 탭에서 폴더 지정 시 클로드가 직접 읽고 만들고 정리
  • "질문하기"에서 "일 시키기"로 전환되는 자리
  • 여러 단계 작업 스스로 계획, 실행 전 승인 요청, 종료 후 보고
  • 파일 정리·보고서·스프레드시트·발표자료 자동 생성, Google Drive·Gmail·DocuSign 연결
  • Claude Desktop 필수, Pro 이상 유료 플랜
CLI vs 데스크톱용도 기준
  • Claude Code CLI 장점 자동화·스크립트 최적, 훅·스킬·MCP 전부 지원, 파이프라인·반복 자동화
  • Claude Code CLI 단점 터미널 기본 지식 필요, 시각 작업 불편, 학습 시간 필요
  • Claude Desktop 장점 화면 친화, 비개발자 바로 사용, Projects·드래그앤드롭, CLI와 세션 공유
  • Claude Desktop 단점 훅·고급 자동화 불가, 파이프라인 제한, 설치·업데이트 수동
  • 개발·자동화는 CLI, 시각 작업이나 비개발자는 데스크톱이 기준이며 둘을 함께 써도 된다

요약 데스크톱 앱은 채팅·Code·Cowork 세 영역이 역할을 나눠 맡고, CLI와 데스크톱 중 고를 때는 자동화가 필요한지를 기준으로 삼는다.

명령어 읽는 법

CLI란

명령 한 줄의 구조를 읽을 줄 알면 처음 보는 명령도 뜻을 짐작할 수 있다.

CLI 기본 구조[도구] [명령] [--옵션] [인수]
  • 예 claude mcp add --transport http notion https://mcp.notion.com/mcp
  • 이 예시에서 도구는 claude, 명령은 mcp add, 옵션은 --transport http, 인수는 notion과 주소다
  • 6회차에서 입력한 명령이 이미 이 구조
이 과정 CLI 3종Claude Code · GitHub CLI · Antigravity CLI
  • Claude Code 파일 편집·코드 실행·MCP·스킬(지금까지 학습분)
  • GitHub CLI(gh) 저장소·PR·이슈 관리
  • Antigravity CLI(구 Gemini CLI) 구글 AI에 터미널에서 질문
  • 반복 작업을 스킬로 자동화, 여러 도구를 파이프라인으로 연결

요약 CLI 명령은 도구·명령·옵션·인수 순서로 읽으며, 이 과정에서 다룬 CLI 3종을 연결하면 복잡한 자동화도 가능해진다.

GitHub CLI

GitHub 계정만 있으면 터미널에서 저장소와 PR을 직접 다룰 수 있다.

01GitHub 가입이메일·비밀번호·사용자명 → 이메일 인증
  • github.com/signup에서 가입, 무료 플랜 시작
  • 이미 계정 있으면 건너뛰기
  • GitHub는 코드 버전 관리와 원격 저장소 백업, 팀 협업에 쓴다

gh repo list

  • --scopes 뒤 목록은 scope, 즉 권한 범위 항목이다
  • gh repo list에 내 저장소 표시되면 완료
04스킬 만들기직접 명령 실행 후 스킬 요청

슬라이드 밖 실습

소개 사이트 만들기

사이트 구조를 글로 먼저 적어 두면 클로드가 그대로 세 파일을 만들어 준다.

실습 순서반려견 소개 사이트 예시
  • 작업 폴더에 structure.md 먼저 작성(어떤 페이지·어떤 내용)
  • 그 파일을 근거로 클로드가 index.html · style.css · script.js 3파일 생성
  • 같은 폴더에 7회차 카드뉴스·QR 스킬 결과물이 남아 사이트에 넣는 흐름으로 연결
응용반려견 자리를 바꿔 재사용
  • 포트폴리오 · 동아리 소개 · 가게 메뉴로 대체 가능
  • 핵심은 구조를 먼저 글로 쓰고 그다음 만들게 하는 순서다
  • 4회차 플랜 모드(계획 승인 후 실행)와 같은 발상

요약 structure.md를 먼저 쓰고 3파일을 만드는 순서는 4회차 플랜 모드와 같은 발상이다.

먼저 껐다 켜기

당황할 때 대처법

막히는 상황 대부분은 순서대로 시도하면 5분 안에 풀린다.

00VS Code 재시작가장 흔한 해결책. 절반 이상 이걸로 해결
  • 파일 → 종료(Windows Alt+F4)로 창 전부 닫기, 창 하나만 닫으면 잔존 가능
  • 다시 열고 같은 작업 폴더에서 터미널에 claude 새로 실행
  • 작업 파일은 그대로 유지, 대화만 새로 시작. 이어가려면 claude --continue
  • 그래도 같으면 컴퓨터 재시작. 설치 직후 명령 미인식은 재시작으로 대부분 해결
01claude 찾을 수 없음CommandNotFoundException류 메시지
  • 터미널 창 닫고 새로 열기(설치 후 연 터미널은 새 명령 모름)
  • 그래도 같으면 npm install -g @anthropic-ai/claude-code 재실행 후 00번
  • 슬래시 붙여 /claude로 입력하면 파워셸이 경로로 인식해 실패, 슬래시 제외, claude만 입력
02스크립트 실행 차단윈도우 보안 정책
Set-ExecutionPolicy RemoteSigned
  • 파워셸 관리자 권한으로 열어 입력, 물음에 A 입력 → 00번
03슬래시 명령 오류claude 실행 밖에서 입력
  • /mcp /plugin 등은 claude 실행 중인 대화 안에서만 동작
  • 터미널에 바로 입력하면 파워셸이 모르는 명령이라 오류. claude 먼저 실행 후 그 안에서 입력
04클로드 멈춘 것 같음작업 중 vs 무응답 구분
  • 점이 움직이거나 Thinking이 뜨면 작업 중이며, 파일이 많으면 1~2분 걸린다
  • 중단은 Esc 1회(현재 동작만 중단, 대화 유지)
  • 완전 종료는 /exit 또는 Ctrl+C 2회
  • 백그라운드 작업은 /tasks에서 진행 확인
  • 무반응이면 00번
05답이 엉뚱함문맥 포화
  • /context로 사용량 확인
  • /compact로 요약 또는 /clear로 새로 시작
  • 새로 시작해도 파일·CLAUDE.md는 유지, 지켜야 할 내용은 CLAUDE.md에 기록(4회차 내용)
06파일 잘못 수정되돌리기
  • Esc 2회 또는 /rewind
  • 대화만 되돌릴지, 파일 변경까지 되돌릴지 선택 가능. 실수 복구용 Ctrl+Z에 해당
07허락 창 반복자동 승인 모드 전환
  • Shift+Tab으로 모드를 전환하며, 편집 자동 승인 모드에서는 파일 수정 확인을 생략한다
  • --dangerously-skip-permissions는 권한 확인 자체를 끔, 꼭 필요한 순간에만 사용 후 평소 모드 복귀
08파일 없음·엉뚱한 곳 생성작업 폴더 확인
  • VS Code 파일 → 폴더 열기로 작업 폴더가 열려 있는지 확인
  • 터미널 줄 맨 앞 경로가 그 폴더인지 확인, 아니면 터미널 닫고 새로 열기
  • 파일을 탐색기에서 대화창으로 끌어다 놓으면 경로 정확히 전달
09pip·npm 빨간 글씨설치 오류 대응
  • 오류 문구 전체 복사해 클로드에게 "이 오류 뭐야, 고쳐줘"로 전달
  • pip 미인식 시 python -m pip install 이름으로 대체
  • 회사·학교망 차단 가능성, 다른 망에서 재시도
10터미널 한글 깨짐표시 문제. 내용은 정상
  • 터미널에 chcp 65001 입력 후 재확인, 또는 클로드에게 "터미널 한글이 깨져, 고쳐줘"
  • 카드뉴스 이미지 한글 깨짐은 14절 3번 참조
11로그인 풀림·한도 안내재로그인 또는 모델 전환
  • /login으로 재로그인, 브라우저에서 claude.ai 계정 진입
  • 한도 안내 시 /config의 Usage 탭에서 리셋 시각 확인
  • 급하면 /model에서 가벼운 모델로 전환
12MCP 인증 창 안 열림수동 인증
  • /mcp에서 해당 서버 선택, Authenticate 재클릭
  • 브라우저 팝업 차단 해제, 또는 터미널에 표시된 주소 복사해 직접 열기
  • 그래도 안 되면 00번 후 재시도

요약 어떤 문제든 오류 문구를 그대로 복사해 상황 한 줄과 함께 전달하고, 그 전에 항상 00번 VS Code 재시작부터 시도한다.

각주

알아두면 유익한 것

슬라이드에는 없지만 실습 중 실제로 자주 부딪히는 것들을 모았다.

01description 역할자동 호출 판단 근거
  • "회의록 정리"처럼 실제로 말할 낱말을 넣으면 슬래시 명령 없이도 발동
02pip 실패 대처python -m pip 대체
  • pip는 Python 기본 내장. 사용자 폴더명이 한글이거나 PATH(실행 파일 찾는 경로 목록)가 잘못된 경우 python -m pip install pillow로 대부분 해결
03한글 폰트 깨짐 대처ImageFont.truetype()에 한글 글꼴 경로 지정
  • Pillow 기본 글꼴은 영문 전용
  • Windows는 C:\Windows\Fonts\malgun.ttf(맑은 고딕) 사용
  • 클로드에게 "한글 폰트로 바꿔줘" 요청 시 이 경로를 찾아 적용
04플러그인의 정체스킬·훅·MCP 설정 파일과 동일
  • 5·6·7회차에서 배운 구성 요소와 같은 파일
  • 설치한 플러그인 폴더를 확인해 보면 복습이 된다
05설치 범위 3계층settings.json 3계층과 대응
  • User·Project·Local은 전역·프로젝트·로컬과 같은 구분이다
  • 팀 공유는 Project, 개인 실험은 Local
06LSP·commit의 뜻편집기 표준 규약과 Git 저장 동작
  • LSP(Language Server Protocol)는 편집기가 "이 변수의 정의는 어디"를 묻는 표준 규약이며, VS Code 자동완성이 이 원리로 동작한다. 코드 작업이 없으면 건너뛰어도 된다
  • commit은 Git에서 지금 상태를 이름 붙여 저장하는 동작이다
07gh scope 7종권한별 허용 범위
  • repo 저장소 읽기·쓰기, delete_repo 삭제, workflow 자동 실행 편집, gist 코드 조각 공유, read:org 조직 조회, admin:public_key SSH 키 등록, write:packages 패키지 업로드
  • 삭제 권한은 꼭 필요할 때만 부여
08PAT 취급 주의비밀번호급 문자열
  • 채팅창·공유 문서·블로그에 붙여넣는 순간 유출
  • 브라우저 인증은 터미널에 뜬 8자리 코드를 github.com에 입력하는 방식이라 코드만 넣으면 인증 완료
09클로드 -p 모드claude -p도 비대화형
  • 다른 프로그램·스킬이 AI를 부품처럼 부를 때 쓰는 방식
  • "bash로 agy -p 호출 스킬" 성립 근거
10두 AI 호출 문맥 비용Antigravity 답변이 클로드 문맥에 편입
  • -p 질문에 "3줄로"처럼 길이 지정 필요, 문맥 절약
11정적 사이트 배포GitHub Pages로 무료 배포
  • index.html·style.css·script.js 구조면 서버 없이도 도는 정적 사이트가 된다
  • GitHub 저장소에 올리고 Pages 기능 켜면 무료 주소 생성. 10절 계정으로 바로 가능
  • 클로드에게 "GitHub Pages로 배포해줘" 요청 시 gh 명령으로 처리
12설치물 정리 원칙5·6회차 마무리 원칙
  • 플러그인·MCP·스킬을 많이 설치할수록 클로드가 매번 읽는 양 증가 → 속도 저하·토큰 소모
  • 오늘 할 일에 맞춰 켜고 끄기

요약 이 12개 항목은 보안·성능·복습 범주로 나뉘며, 그중 3번 한글 폰트와 9번 -p 모드는 오늘 바로 적용할 수 있다.

본문 밑줄 낱말 19개

스킬
  • 파일 하나로 만드는 새 슬래시 명령어. 자주 시키는 일을 한 줄로 축약 ↩

  • 남이 만든 기능 모음. 설치 후 불러오기 한 줄로 사용 ↩

  • pip = Python 패키지 설치 명령. npm = Node.js 패키지 설치 명령 ↩

  • Python 이미지 처리 라이브러리. 카드뉴스 실습 기본 도구 ↩
