설치

프로그램 3종

오늘은 VS Code·클로드 데스크톱·옵시디언 세 프로그램만 설치하면 되고, 파워셸은 윈도우에 이미 있어 따로 설치하지 않는다.

01VS Code 설치파일 편집 프로그램. 수업 메인 화면
  • code.visualstudio.com/download → Windows → 받은 파일 실행
  • 동의 체크 → 다음
  • 추가 작업 선택: "Code(으)로 열기" 2줄 체크
  • 설치 → 완료
  • VS Code 창 열림
02한국어 팩메뉴 한국어화. 확장 1개 설치
  • Ctrl+Shift+X → 검색 Korean
  • 맨 위 항목 Install
  • 우하단 재시작 단추 클릭
  • 메뉴 한국어 표시
03클로드 데스크톱 설치클로드 대화 프로그램. 안에 Code 단추
  • claude.ai/download → Windows → 설치
  • 기존 클로드 계정 로그인
  • 왼쪽에 Chat · Code 표시
  • Code가 안 보이면 유료 구독이 아니라는 뜻이다
04옵시디언 설치메모 프로그램. 클로드 결과물 열람 화면
  • obsidian.md/download → Windows → 설치. 무료
  • 계정 생성 화면 → 건너뛰기
  • 첫 화면 표시. 여기서 대기 → 5번

요약 세 프로그램 설치를 마쳤고 옵시디언은 첫 화면에서 기다리는 상태다.

폴더

업무 폴더 1개

업무 폴더 하나를 만들어 VS Code·클로드·옵시디언이 함께 쓰게 한다.

05업무 폴더 생성탐색기는 노란 폴더 아이콘
  • 탐색기 → 문서
  • 빈 곳 우클릭 → 새로 만들기 → 폴더
  • 이름 업무
  • 문서 안에 업무 폴더
06하위 폴더 4개앞 숫자는 정렬 순서 고정
  • 업무 진입 → 같은 방법으로 폴더 4개
  • 00_우체통 미분류 메모
  • 01_자료 참고 자료
  • 02_프로젝트 진행 중인 일
  • 99_시스템 규칙 · 기록
  • 업무 안에 폴더 4개, 숫자 순 정렬
07VS Code로 열기VS Code는 파일이 아니라 폴더 단위로 열기
  • 탐색기 → 업무 우클릭 → Code(으)로 열기
  • "작성자를 신뢰합니까" → 예
  • VS Code 왼쪽 최상단 업무, 아래 폴더 4개
08파일 1개 생성.md는 글자 파일 표시
  • 왼쪽 업무 오른편 새 파일 아이콘(종이 모양)
  • 이름 00_할일.md → Enter
  • 본문 아무 글 → Ctrl+S
  • 왼쪽 목록에 00_할일.md
09아래 칸 열기파워셸. 글자 명령 창, 1회차 설치 명령 입력 자리
  • Ctrl+`(숫자 1 왼쪽 키) → 아래 칸 표시
  • 아래 글 복사 → 붙여넣기 → Enter
Get-Date
  • 오늘 날짜가 나오면 성공이다. 명령 창은 붙여넣기와 Enter가 전부다

요약 업무 폴더와 하위 폴더 4개를 만들고 VS Code로 열어 파일 1개와 명령 1줄까지 실습했다.

연결

옵시디언 · 클로드 → 같은 폴더

옵시디언과 클로드가 같은 업무 폴더를 보게 되면 오늘 목표는 끝난다.

10옵시디언으로 열기볼트는 옵시디언이 연 폴더
  • 옵시디언 첫 화면 → 폴더를 볼트로 열기
  • 업무 선택
  • 왼쪽에 00_할일.md + 폴더 4개(8번 파일 그대로)
11옵시디언 설정 2개톱니는 왼쪽 하단
  • 톱니 → 파일 및 링크 → 새 노트 생성 위치 → 아래 지정한 폴더 → 00_우체통
  • 톱니 → 편집기 → 맞춤법 검사 → 끔
  • Ctrl+N 새 메모 → 00_우체통 안에 생성
12클로드에 폴더 지정세션은 대화 1판, 허용 창은 파일 조작 전 확인
  • 클로드 데스크톱 → Code
  • 새 세션 → 폴더 선택 → 업무
  • 아래 글 붙여넣기 → Enter → 허용 창 → 허용
00_우체통에 오늘 날짜로 테스트 메모 파일 하나 만들어줘
  • 생성 파일이 옵시디언·VS Code 양쪽에 뜨면 세 프로그램이 한 폴더를 본다는 뜻이다
13규칙 파일 생성CLAUDE.md는 클로드가 세션마다 먼저 읽는 규칙
  • VS Code → 새 파일 → 이름 CLAUDE.md(대문자) → Enter
  • 아래 글 붙여넣기 → Ctrl+S
# 작업 규칙
- 결론부터, 짧게. 인사말 없이
- 새 문서는 00_우체통에 만든다
- 모르는 것은 지어내지 말고 [확인 필요]라고 쓴다
- 파일을 지우기 전에 묻는다
  • 클로드 새 세션 → "규칙 파일 읽었어?" → 4줄 답변
  • 같은 지적을 두 번 받으면 그 자리에서 규칙 1줄을 추가한다

요약 옵시디언·클로드·VS Code가 업무 폴더 하나를 공유하고 규칙 파일까지 만들어 오늘 준비를 마쳤다.

옵시디언 생략

메모 프로그램 생략 시 경로

옵시디언 없이 VS Code와 클로드 두 개만으로도 오늘 실습을 마칠 수 있다.

건너뛸 단계옵시디언 관련 3개
  • 4번(옵시디언 설치) · 10번(볼트로 열기) · 11번(옵시디언 설정)은 건너뛴다
  • 1~3 · 5~9 · 12~13번은 그대로 진행한다
파일 읽는 자리VS Code 미리보기 또는 메모장
  • VS Code 왼쪽에서 .md 파일 클릭 → Ctrl+Shift+V를 누르면 제목·목록이 꾸며진 미리보기가 뜬다
  • 미리보기를 끄려면 탭을 닫고, 원문을 고치려면 그냥 클릭한다
  • 탐색기에서 파일을 더블클릭하면 메모장이 열리고 원문 그대로 보인다
12번 성공 기준옵시디언 칸 대신 VS Code 칸
  • 클로드가 만든 파일이 VS Code 왼쪽에 나타나면 두 프로그램이 같은 폴더를 본다는 뜻이다
차이옵시디언 유무
  • 옵시디언이 있으면 메모끼리 연결([[이름]])하고 전체 검색도 되고 읽기 화면도 따로 생긴다
  • 옵시디언이 없어도 파일 편집·미리보기만으로 수업 진행에는 지장이 없다
  • 나중에 옵시디언을 추가할 땐 4·10·11번만 실행하면 되고 파일·폴더는 그대로다

요약 옵시디언은 선택 사항이고, 없으면 VS Code 미리보기(Ctrl+Shift+V)로 대신할 수 있다.

클로드 종류

이름 8개 · 그림으로 구분

이름은 여덟 개지만 전부 같은 클로드이고, 여는 곳(웹·앱·터미널)과 시키는 일(대화·파일 조작)만 다르다.

클로드 웹claude.ai. 인터넷 창에서 대화
  • 설치 없음. 브라우저 로그인만
  • 대화 · 파일 첨부 · 분석 · 글쓰기
  • 내 컴퓨터 폴더 조작 불가
클로드 데스크톱설치형 앱. 왼쪽에 탭 3개
  • Chat은 클로드 웹과 같다
  • Code는 뒤에 나오는 클로드 코드다
  • Cowork는 뒤에 나오는 코워크다
클로드 코드폴더 안에서 파일을 만들고 고치는 클로드. 실행 방법 3가지
  • 파일 생성 · 수정 · 명령 실행 · 폴더 정리
  • 실행 방법 ① 데스크톱 Code 탭(설치 없음) ② VS Code 아래 칸 ③ 파워셸. ②③은 1회차 설치 후 claude 입력
  • 이 수업의 학습 대상
코워크(Cowork)데스크톱 Cowork 탭. 명령어 입력 생략, 화면으로 일 시키기
  • 폴더 지정 → 클로드가 읽고 만들고 정리
  • 여러 단계 작업은 계획 제시 → 승인 → 실행 → 보고 순으로 진행한다
  • 용도는 파일 정리·보고서·발표자료 작성이며 Google Drive·Gmail·DocuSign과 연결된다
  • Code는 터미널·훅·스킬 등 개발 도구 전부를 쓰고, Cowork는 비개발 업무용 화면이라 명령어 입력이 없다
  • Claude Desktop 필수, Pro 이상 유료
VS Code로 구동VS Code 아래 칸에 claude 입력. 파일 · 대화 한 화면
  • VS Code로 업무 폴더 열기 → Ctrl+` → claude → Enter
  • 왼쪽은 파일 목록, 가운데는 내용, 아래는 클로드 대화 창이다
  • 클로드가 고친 파일이 왼쪽 · 가운데에 바로 반영
파워셸로 구동검은 창에 claude 입력. 글자만
  • 시작 → PowerShell → cd 업무 → claude
  • VS Code 아래 칸과 완전히 같은 프로그램. 파일 목록 화면만 없음
  • VS Code가 없는 PC에서 빠르게 한 가지 작업만 할 때 쓴다
CLICommand Line Interface는 글자 명령으로 프로그램 조작
  • GUI(화면 클릭)의 반대말. 글자 한 줄 + Enter
  • claude · gh(GitHub) · agy(구글 Antigravity) 전부 CLI
  • 자동화·반복·도구 연결에 강하지만 화면이 없어 명령을 외워야 한다
클로드 vs 코덱스같은 종류의 도구, 만든 회사가 다름

이 수업기준 도구범위 밖
  • 둘 다 "폴더 안에서 파일을 만지는 AI 에이전트". 개념 · 조작 방식 거의 동일
  • 하나를 익히면 다른 것도 바로 쓸 수 있고, 차이는 회사·모델·계정뿐이다

낱말 풀이

본문 밑줄 낱말 12개

왼쪽 = 낱말. 오른쪽 = 뜻. ↩ = 본문 복귀.

VS Code
  • 파일을 열어 보고 고치는 프로그램. 메모장의 확장판
  • 왼쪽 파일 목록 · 가운데 내용 · 아래 명령 칸 ↩ 1번
확장 · Install
  • 확장 = VS Code에 덧붙이는 추가 기능(한국어 팩 등). Install = 설치 ↩ 2번
클로드 데스크톱
  • 클로드 대화 프로그램. 인터넷 창 claude.ai의 설치판 ↩ 3번
Code · 클로드 코드
  • 내 폴더에 들어와 파일을 만들고 고치는 클로드. Chat = 대화만, Code = 파일 조작
  • 실행 방법 2가지: 데스크톱 Code 단추(오늘) · VS Code 아래 칸에 claude 입력(1회차). 둘 다 같은 것 ↩ 3번
유료 구독
  • 월 결제 클로드 계정. Code 단추 = 유료 전용 ↩ 3번
옵시디언
