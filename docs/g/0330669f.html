왜 이 시간이 중요한가

종규님께

부동산 DB를 구축하고 가공하는 일을 클로드에게 맡기려면, 클로드가 어느 폴더의 어떤 파일을 건드려도 되는지를 먼저 정해 두어야 합니다. 3회차가 바로 그 울타리를 치는 시간입니다.

  • 설정 파일은 "이 폴더에서는 이렇게 일해라"를 적어 두는 곳입니다. 부동산 자료 폴더에는 원본 엑셀을 지우지 말라는 규칙을, 실험 폴더에는 자유롭게 해도 된다는 규칙을 따로 둘 수 있습니다.
  • 권한 모드는 클로드가 파일을 고칠 때마다 물어볼지, 알아서 진행할지를 정합니다. 처음에는 매번 묻는 모드로 시작하는 것이 안전합니다.
  • 슬래시 명령어는 지금 어떤 모델이 붙어 있고 사용량이 얼마나 남았는지 확인하는 계기판입니다.

읽는 법 1절은 지난 시간 복습이라 아는 내용이면 넘겨도 됩니다. 2절부터 5절이 이번 수업 본론이고, 6절 실습을 해 두면 수요일 4회차가 편해집니다.

폴더 · 전역 · 프로젝트

지난 회차 복습

수업은 1~2회차 내용을 다시 짚으면서 시작했습니다. 폴더 하나가 프로젝트 하나라는 감각이 이후 설정 파일 이야기의 바탕이 됩니다.

  • VS Code는 프로젝트별로 폴더를 만들어 관리합니다. 작업 폴더를 지정해 두고 씁니다.
  • 클로드 코드는 계정 하나로 여러 곳에서 접속할 수 있지만, 로컬에서 동작하기 때문에 대화 내용은 각각 따로 남습니다.
  • 전역 설정은 통상 C드라이브 사용자 폴더 아래 .claude 폴더에 있습니다. 이 폴더의 파일을 지우고 다시 설치하는 것도 가능합니다.
  • 클로드를 쓸 폴더는 자유롭게 정해도 되지만, 반드시 폴더를 먼저 만들어 두고 그 안에서 시작합니다.
  • md 파일에 지시사항을 담아 둘 수 있습니다. /init을 실행하면 새 환경에서 CLAUDE.md를 만들어 줍니다.
  • CLAUDE.md는 규칙 파일입니다. 폴더마다 따로 두면 프로젝트별로 다른 규칙이 적용됩니다.

수업 중 질문 폴더별로 CLAUDE.md를 만들고 규칙을 다르게 쓰면 폴더마다 각각 적용되나요?

됩니다. 프로젝트별로 다르게 가져갈 수 있습니다.

전역

~/.claude

사용자 폴더 아래에 있습니다. 모든 프로젝트에 공통으로 적용됩니다. 물결표가 붙어 있으면 전역을 읽는 중이라는 뜻입니다.

프로젝트

./.claude

작업 폴더 안에 있습니다. 그 프로젝트에서만 적용됩니다.

3회차 본론

settings.json · 설정이 놓이는 세 계층

환경설정 파일입니다. 특정 동작을 통제하는 데 씁니다. 프로젝트는 곧 폴더라고 보면 됩니다.

1 전역 설정

~/.claude/settings.json

모든 프로젝트에 깔리는 바탕 설정입니다.

2 프로젝트 설정 · 다 같이 쓰는 것

.claude/settings.json

회사 공지문에 해당합니다. 이 프로젝트를 쓰는 사람이면 누가 써도 똑같이 돌아가야 하는 규칙을 적습니다.

3 로컬 설정 · 나만 쓰는 것

.claude/settings.local.json

내 책상 서랍 메모에 해당합니다. 이 컴퓨터에서만 적용되고 다른 사람의 컴퓨터와는 무관합니다.

우선순위 전역 → 프로젝트 → 로컬 순으로 아래쪽이 위쪽을 덮습니다.

만드는 법 그냥 만들라고 하면 전역에 생길 수 있으니, 프로젝트에 두려면 위치를 지정해서 만들라고 시킵니다. 만들어진 파일은 VS Code 탐색기에 뜨니 더블클릭해서 편집하면 됩니다.

주요 키 네 가지

  • model → 이 프로젝트에서 쓸 기본 모델을 지정합니다.
  • permissions → 허용(allow)과 차단(deny) 규칙 목록입니다.
  • env → 환경 변수를 주입합니다.
  • hooks → 정해진 시점에 명령을 실행합니다. 5회차 범위입니다.

실습 흐름

  • "rm 차단 규칙 추가해줘"라고 요청합니다.
  • "note.txt 삭제해줘"를 입력해 차단 메시지가 뜨는지 확인합니다.
  • settings.json 내용을 열어 규칙이 들어갔는지 봅니다.

보안 · 개인정보 클로드 코드는 작업 폴더 밖으로 파일을 쓰지 못하도록 제한돼 있습니다. 상위 폴더에 접근하려면 별도 허가가 필요합니다.

대화 데이터의 학습 이용 거부는 claude.ai 설정의 데이터 개인정보 보호 항목에서 끕니다.

Shift + Tab

권한 모드

모드 전환은 Shift+Tab입니다. 수업자료 용어 기준으로 네 가지를 정리했습니다.

1 일반 모드

편집과 명령을 매번 승인받습니다.

2 편집 자동 승인 모드 (accept edits)

파일 편집은 자동으로 승인되고 코드 변경이 진행됩니다. 터미널 명령은 여전히 물어봅니다.

3 플랜 모드

읽기와 탐색만 가능합니다. 편집과 실행은 할 수 없고, 계획을 세워 승인받은 뒤에 실행합니다.

4 욜로 모드

claude --dangerously-skip-permissions

승인 절차 자체를 건너뜁니다. /exit 또는 Ctrl+C로 종료하고, 위쪽 방향키로 이전 명령을 다시 불러올 수 있습니다.

종규님 권장 부동산 원본 자료가 있는 폴더에서는 일반 모드나 플랜 모드로 시작하세요. 욜로 모드는 되돌릴 수 없는 삭제도 그대로 실행하므로, 복사본 폴더에서만 쓰는 것이 안전합니다.

모드 구성은 버전에 따라 바뀔 수 있으니, 헷갈리면 그때그때 클로드에게 직접 물어보면 됩니다.

슬래시로 시작하는 것들

기본 명령어와 config

슬래시를 붙이면 명령대로 수행합니다. 전체 목록은 /help에서 볼 수 있습니다.

기본 명령어

  • /init → 새 환경에서 CLAUDE.md를 만들어 줍니다.
  • /clear → 대화를 초기화합니다.
  • /model → 모델을 바꿉니다.
  • /login · /logout → 계정 로그인과 로그아웃입니다.
  • /help → 전체 명령어 목록입니다.

/config 세 개 탭

버전, 세션, 계정, 모델, IDE 연결, MCP 상태를 한눈에 봅니다. 지금 무엇이 붙어 있는지 확인하는 자리입니다.

세부 동작을 켜고 끕니다. Auto-compact, Show tips, Reduce motion, Thinking mode, Rewind code, Verbose output, Terminal progress bar, Show turn duration, Default permission mode, Respect .gitignore, Always copy full response, Auto-update channel, Theme, Notifications, Output style, Language, Editor mode, Show PR status footer, Model, Auto-install IDE extension, Claude in Chrome, Enable Remote Control.

세션 사용량과 주간 사용량, 그리고 리셋 시각을 봅니다.

Todos · Task 목록

  • 내장 도구는 TaskCreate · TaskList · TaskUpdate 세 가지입니다.
  • 상태는 pending → in_progress → completed 순으로 흘러갑니다.
  • 활용 문구는 "○○○ 작업을 todo 리스트를 세워서 순차적으로 진행해줘" 입니다.
  • 실습은 practice 폴더 생성 → readme.txt 작성 → 트리 출력을 3단계로 순차 실행했습니다.

모델 · 검색 · 브라우저

모델 선택, 웹 검색, 클로드 인 크롬

작업 성격에 따라 모델을 고르고, 최신 정보가 필요하면 웹 검색이 붙고, 브라우저까지 연결하면 화면 위 작업도 맡길 수 있습니다.

모델 네 가지

  • Haiku → 가장 빠릅니다. 간단하고 양이 많은 작업에 씁니다.
  • Sonnet → 속도와 성능의 균형입니다. 기본 추천입니다.
  • Opus → 복잡한 작업의 기본값입니다. 에이전트 코딩에 씁니다.
  • Fable → 최고 성능입니다. 가장 어려운 문제에 씁니다.

웹 검색

  • 따로 시키지 않아도 최신 정보가 필요하다고 판단하면 스스로 검색합니다.
  • 명시적으로 쓰려면 "○○○ 주제 웹조사해줘"라고 씁니다.
  • 실습 프롬프트는 "오늘 기준 최근 7일 이내에 발행된 AI 에이전트 관련 기사나 글을 웹조사해줘. 각 항목의 주요 내용과 실제 출처 링크도 함께 정리해줘" 였습니다.

Claude in Chrome

수업에서는 개념 설명 뒤 MCP 연동 방법을 배우고, 설치를 요청해 연결하는 데까지 실습했습니다. 부동산 정보 사이트에서 자료를 긁어 오는 일이 이 기능의 자리입니다.

  • 할 수 있는 일은 라이브 디버깅, 디자인 검증, 웹앱 테스트, 로그인이 필요한 웹앱 접근(구글 문서·Gmail·Notion), 데이터 추출, 반복 작업 자동화, 세션 녹화입니다.
  • 지원 브라우저는 Chrome과 Edge입니다. Brave와 Arc는 지원 대상 밖입니다.
  • 설치 순서는 크롬 웹스토어에서 확장 프로그램 설치 → claude --chrome으로 실행하거나 /config에서 기본 활성화 → /mcp → chrome for claude → Enable 입니다.
