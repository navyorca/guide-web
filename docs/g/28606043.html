AIX 개편 신규·변경 (260727 확정분)

구과목 → AIX 전환 규칙 (260822 사업부 공지)

  • 포토샵 400,000 → AIX포토샵 500,000 / 일러스트 400,000 → AIX일러스트 500,000
  • 동일 과목을 신과정으로 바꾸는 것은 차액 결제 없이 인트라넷 배정게시판(댓글배정)으로 변경 가능하다. 10만원 차액을 청구하지 않는다.
  • 동일 과목이 아니면 특처 작성 필수. 예) 포토샵(40만) → AIX일러스트(50만)는 과목이 다르므로 댓글배정 불가.
  • 적용 판단은 보유 과목명 기준이다. 포토샵 보유자는 AIX포토샵으로만, 일러스트 보유자는 AIX일러스트로만 무상 전환된다.

수강료는 단계(1과목) 기준. 단계 표기가 1~3이면 3개월 연속 수강 시 총액은 단계 수강료 × 단계 수. 구과목 편성은 개편 적용 전까지 위 표를 계속 사용한다.

과정 구조·시수·구과목 매핑 정본은 AIX_모듈개편_정본. 아래 표에 없는 AIX 과정의 수강료는 그 문서의 통합로드맵 V1 표를 참조한다(260728 기준: 마케팅영상 24H 50만 · 유튜브 올인원클래스 32H 100만 · 실전 영상편집 24H 50만 · 2D 모션 48H 100만 · 피그마 90H 150만 · 바이브코딩 90H 180만 · 포토 24H 50만 · 일러 24H 50만 · 공간기획&인테리어 설계 48H 90만 · BIM 기초 64H 100만 · 공간VR시각화 48H 100만).
