Course 01

AI 에이전트 → 실행까지 맡기는 AI

일반 AI는 답을 만들어 주고 사람이 옮겨 붙입니다. 에이전트는 파일을 직접 열고, 프로그램을 호출하고, 결과를 확인해 스스로 고칩니다. 이 차이를 이해시키는 것이 상담의 출발점입니다.

01 환경 인식

파일 · 웹 · API 등 외부 환경을 스스로 탐색하고 정보를 수집합니다.

02 자율 판단

수집한 정보를 바탕으로 다음 행동을 스스로 결정합니다.

03 도구 활용

코드 실행 · 파일 편집 · 외부 서비스 호출로 실제 작업을 수행합니다.

04 반복 수정

결과를 확인하고 부족하면 스스로 고치며 목표 달성까지 반복합니다.

3단계 로드맵

STEP 1 · 프롬프트 엔지니어링

AI 모델 비교와 선택, 프롬프트 구조화 기법, 실무 활용 예시 실습.

STEP 2 · 기초

Claude Code 기본 사용법, Sub Agent · Hooks · MCP, Skills 제작과 자동화, 메신저 알림 연동.

STEP 3 · 심화

엑셀 · 워드 · PPT 스킬 구현, Notion DB + API 자동화, 세컨드 브레인 · PM 에이전트 구축, 나만의 하네스 설계.

두 과정이 만나는 지점

따로 소개할 필요가 없는 대목입니다. 피그마 과정의 마지막 주차가 에이전트 과정의 도구를 그대로 씁니다. 디자인을 코드로 옮기고 실제 URL로 배포하는 단계에서 Figma MCP와 AI 에이전트가 동원됩니다.

디자인 → 코드 → 배포, 세 단계

AI 피그마 90시간 과정 수료 후 이어지는 심화 포트폴리오 수업의 운영 결론이기도 합니다.
