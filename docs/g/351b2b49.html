1. 설치 3개

이미 설치한 것은 건너뜀.

01클로드 데스크톱
  • claude.ai/download → Windows용 받아서 설치 → 로그인
  • 왼쪽에 Chat · Code 보임
  • Code가 없으면 유료 구독 계정이 아님
02Git
  • git-scm.com/download/win → 받은 파일 실행
  • 고르는 화면은 손대지 말고 전부 Next → Install
  • 설치 끝나면 클로드 데스크톱 껐다 켜기
03크롬 확장
  • 크롬에서 claude.com/claude-for-chrome → Chrome에 추가
  • 확장 아이콘 클릭 → 클로드 데스크톱과 같은 계정으로 로그인
  • 퍼즐 아이콘 → 클로드 옆 핀 눌러 고정
  • 크롬 오른쪽 위에 클로드 아이콘 보임

2. 폴더 지정

04폴더 선택
  • 클로드 데스크톱 → Code → 폴더 선택
  • 문서 안에 업무 폴더를 새로 만들어 고름
  • 평소 쓰던 업무 폴더를 그대로 고름
  • 대화창 위에 폴더 이름 보임

3. 설치 글 붙여넣기

05신입용 설치 글
  • 복사 → Code 탭 대화창에 붙여넣고 전송
  • 허용 창이 뜨면 허용 누름
아래 순서대로 설치해줘. 기존 파일은 덮어쓰지 말고 합쳐줘.

1. git --version 으로 Git 설치를 확인한다. 없으면 멈추고 "Git 설치 필요"라고만 알린다.
2. 사용자 폴더의 .claude 폴더에 settings.json 이 있으면 같은 폴더에 settings.json.bak_날짜시각 으로 백업한다.
3. .claude/settings.json 에 아래 값을 합친다. 다른 키는 그대로 둔다. allow 는 없는 항목만 덧붙인다. 기존 defaultMode 가 있으면 바꾸지 않는다. 저장 뒤 JSON 문법을 검사하고, 실패하면 백업으로 되돌린다.

{
  "language": "korean",
  "permissions": {
    "defaultMode": "acceptEdits",
    "allow": [
      "Read", "Glob", "Grep", "WebSearch", "WebFetch",
      "mcp__claude-in-chrome__tabs_context_mcp",
      "mcp__claude-in-chrome__read_page",
      "mcp__claude-in-chrome__get_page_text",
      "mcp__claude-in-chrome__find"
    ]
  }
}

4. 지금 연 폴더에 CLAUDE.md 가 없으면 아래 내용으로 만든다. 있으면 건드리지 않는다. 묻지 않고 진행한다.

# 작업 규칙
- 답변은 한국어, 존댓말로 하고 결론을 첫 문장에 쓴다.
- 모르는 수치, 날짜, 이름은 지어내지 않고 [확인 필요]라고 쓴다.
- 수강생은 이름(연락처 뒷4자리)로 쓴다.
- 인트라넷 저장, 메시지 발송, 파일 삭제는 내가 직접 하거나 먼저 묻는다.

5. 열려 있는 크롬 탭 목록을 읽어 크롬 확장 연결을 확인한다. 안 되면 "크롬 연결 안 됨"이라고 적는다.
6. 개인정보(연락처, 비밀번호, 토큰)를 어떤 파일에도 쓰지 않았는지 확인하고, 아래 형식으로만 보고한다.

설치 완료
- Git: 버전
- 권한: 파일 편집은 자동, 명령 실행은 물어봄
- 크롬 연결: 됨 / 안 됨
- 백업: 경로 또는 없음

4. 확인 3가지

앱을 껐다 켠 뒤 Code 탭에서 확인.

한국어
  • 아무 말이나 보냄
  • 한국어 존댓말로 답함
권한
  • "테스트 메모 파일 하나 만들어줘" 입력
  • 묻지 않고 바로 만듦
크롬
  • 크롬을 켜 둔 채 "크롬 탭 목록 보여줘" 입력
  • 열린 탭 이름이 나옴

막힐 때

Code 탭이 안 보임
  • 유료 구독 계정인지 확인
"Git 설치 필요"가 뜸
  • 02번 Git 설치 → 클로드 데스크톱 껐다 켜기
"크롬 연결 안 됨"이 뜸
  • 확장과 클로드 데스크톱 계정이 같은지 확인
  • 크롬을 켜 둔 채 클로드 데스크톱 껐다 켜기
로그인이 계속 반복됨
  • 로그아웃 → 앱 종료 → 다시 로그인
그래도 안 됨
  • 화면 캡처해서 멘토에게 보냄
