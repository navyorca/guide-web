01

02

기억 부여와 파일 · 폴더 제어

에이전트에 규칙과 기억을 넣고, 파일과 폴더를 말로 지시해 정리해 봅니다.

03

환경 설정과 기본 명령어

보안 설정을 먼저 마치고, 승인 방식과 웹 검색 · 할 일 관리 기능을 익힙니다.

04

세션 관리와 작업 나누기

05

작업 분담과 자동 실행

여러 역할로 나눠 일을 맡기고, 정해진 상황에서 자동으로 동작하게 만듭니다.

06

외부 서비스 연동

업무에서 쓰는 서비스를 에이전트와 연결하는 표준 방식을 배우고 직접 적용합니다.

07

반복 작업을 기능으로 굳히기

매번 설명하지 않아도 되도록 자주 하는 작업을 하나의 기능으로 만듭니다.

08

데스크톱 환경 활용
