#팀장님교육

2. 컨택 매뉴얼

2-1. 컨택의 목표와 본질

  • 목표: 고객 니즈 파악 + 방문 상담 예약 (정보 전달이 목적이 아님)
  • 본질: 상대에 대한 궁금증에서 시작 → 제한적인 정보 제공으로 상대가 궁금해하고 기대를 갖게 만들기
  • 원칙: AI 챗봇이 아니므로 단순 스크립트 나열 금지 → 역지사지의 대화로 고객 니즈 파악
  • 핵심: 어디까지나 컨텍은 상담 유도가 목적

2-2. 컨택 전 준비

  1. 수업 과정 숙지
  2. 나만의 스크립트 준비
  3. 고객 정보 사전 확인

2-3. 말투와 언어 표현

  • 기조: 부드러운 말투 → 상냥하게, 천천히, 또박또박
  • 미니꼬리 활용: '~아', '~오' 어미 사용
  • 맞장구: "아아, 그러시군요~" (자주 쓰이는 공감 톤)
  • 전화 특성: 비언어적 표현이 제한 → 말투와 멘트가 아주 중요
  • 호칭: 고객을 '성함+님'으로 호칭 (사모님·사장님 금지)
  • "고객님, 제가 고객님을 ㅁㅁㅁ님으로 불러드려도 괜찮으실까요? 원하시는 호칭이 있으시면 말씀해주세요."

2-4. 상담 실명제 (인삿말 스크립트)


"안녕하세요, ㅁㅁㅁ님 맞으실까요?
SBS아카데미 컴퓨터학원 강남지점입니다.
문의하신 (관심과정) 과정 담당하고 있는 오영선 멘토입니다."
  • 대표DB: 전화를 남겨서 컨택
  • 일반DB: 문의/마케팅 인입 → 모르는 번호라서 통화거절·방어적 태도 가능 → 목적(용건)과 의도를 분명하게 안내

"기다려주셔서 감사합니다. 통화 가능하실까요?
문의 주신 과정은 학습 목적이나 단계별로 수업이 다양해서
자세한 안내를 드리기 위해 전화 드렸어요~"

2-5. 탐색 질문 (고객 니즈 파악)

쿠션 표현: 혹시 / 실례지만 / 괜찮으시다면 / 번거로우실 수 있지만

탐색 항목질문 예시파악 목적
재직 여부"지금 회사 재직 중이실까요?"평일/오전오후/주말 여건 파악
연령"나이가 어떻게 되세요?"국비지원 등 자격 조건 확인
거주지"거주지가 어떻게 되세요?"접근 가능 지점 파악
학습 계기"배우셔야 하는 이유가 있으실까요?"동기 및 니즈 파악
학습 기간"생각하고 계신 학습 기간은 어떻게 되세요~?"과정 설계 기준

2-6. 방문 유도 멘트

  • "유선상 안내도 가능하지만 비대면이다 보니, 직접 시각자료와 함께 설명드리는 게 조금 더 이해하시기 편하실 것 같아요~"
  • "오시는 김에 강의실과 학원 시설을 직접 보여드리면 좋을 것 같아요~"
  • "수업 시간대가 워낙 다양해서 직접 뵙고 커리큘럼을 같이 세워볼 수 있을 것 같아요~ 혹시 방문 가능하실까요?"
  • 로드맵 비교 분석, 전문용어 언급, 학원 내 행사 언급으로 방문 욕구 자극
  • 이벤트 활용: 담당자 특별 할인, 리뷰 작성 혜택(5만원) 어필

2-7. 마무리 멘트

방문 확정 시:


"메가박스 건물 5층으로 올라오셔서 인포데스크에 성함만 말씀해주세요.
그럼 ㅁㅁ일 ㅁ시에 뵙겠습니다. 감사합니다~"

미결 시:


"끝까지 챙겨드리기 → 고민이 많으신 것 같아요.
좋은 소식 있을 때 한번 더 연락드려도 될까요?
궁금한 점이 생기실 때 카톡으로도 상담이 가능하니 편히 말씀주세요."

2-8. 컨택 마음가짐

  • 거절에 대한 두려움 갖지 말 것 → 실전 과정에서 거절은 당연한 것
  • 컨택은 확률 싸움 → 많은 시도 통해 본인만의 통계 데이터 구축
  • 선배 멘토들의 녹취를 들어보며 학습하되 반드시 정답이 아님을 인지 → 본인만의 스타일 만들기
  • 중꺾그마(중요한 건 꺾여도 그냥 하는 마음), 스트롱스트롱(이건 나를 강하게 만들어 주는 수련이다)
