에이전트란 무엇인가

일반 AI는 한 번 답하고 끝나지만, 에이전트는 스스로 판단하고 행동한 뒤 결과를 확인해 다음 행동을 정합니다.

입력→ 판단→ 행동→ 결과 확인→ 다시 판단→ 다음 행동

수업에서 짚은 핵심

  • 에이전트는 실제 PC 내부로 들어와 코드 형식으로 작업하고, 컴퓨터를 직접 통제합니다.
  • 터미널에 명령어를 입력하는 일 자체를 에이전트가 알아서 처리합니다.
  • 개발자는 코드를 아니까 편하게 쓰지만, 비개발자도 본인이 가진 지식을 말로 전달하면 에이전트가 학습하고 문제를 정의해 해결합니다.
  • 터미널 창에서만 작업하지 않으려고 VS Code(비주얼 스튜디오 코드)를 씁니다.
  • 폴더 하나에서 에이전트를 여러 개 쓸 수도 있고, 폴더마다 따로 쓸 수도 있습니다.
  • 프롬프트 엔지니어링은 원하는 자료를 얻으려고 명령을 효율적으로 정리하는 일이지만, 지금은 메모리 관리가 되므로 문맥으로 대화하듯 써도 됩니다.
  • 대화하면서 원하는 방향으로 문맥을 관리해 주면 그에 맞게 작업합니다. 작업할 폴더를 대화창에 드래그해서 넣어도 됩니다.

1~7단계

설치 순서

강사님 말씀대로 이 과정이 제일 까다롭습니다. 운영체제 탭을 고르고 위에서부터 순서대로 진행하세요.

먼저 받아 둘 프로그램

  • Node.js 내려받기 — 클로드 코드가 이 위에서 돌아갑니다.
  • Visual Studio Code 내려받기 — 실제 작업 화면입니다.
  • Git 내려받기 — 작업 이력을 관리합니다.

설치 파일을 직접 받아도 되고, 아래 명령어로 한 번에 설치해도 됩니다. 둘 다 하실 필요는 없습니다.

윈도우는 PowerShell을 열어서 진행합니다. 시작 메뉴에서 PowerShell을 찾아 마우스 오른쪽 버튼으로 관리자 권한으로 실행하세요.

01Git 설치

winget install Git.Git

[1] winget은 윈도우에 기본으로 들어 있는 프로그램 설치 도구입니다. 홈페이지에 들어가지 않아도 이 한 줄로 Git이 설치됩니다.

02Git 설치 확인

git --version

[2] 버전 번호가 한 줄 뜨면 정상입니다. 아무 반응이 없거나 오류가 나면 PowerShell 창을 닫았다가 다시 열고 한 번 더 실행해 보세요. 설치 직후에는 창을 새로 열어야 인식되는 경우가 많습니다.

03Node.js 설치

winget install OpenJS.NodeJS

[3] 클로드 코드는 Node.js의 패키지 형태로 배포됩니다. Node가 없으면 다음 단계의 설치 명령이 아예 실행되지 않습니다.

04Node.js 설치 확인

node -v
npm -v

[4] 두 줄 모두 버전 번호가 나와야 다음으로 넘어갑니다. node는 실행 환경, npm은 그 위에서 프로그램을 설치하는 도구입니다.

맥은 터미널 앱을 열어서 진행합니다. Spotlight(⌘ + 스페이스)에서 "터미널"을 검색하면 됩니다.

01Homebrew 설치

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

[5] Homebrew는 맥에서 프로그램을 설치해 주는 도구입니다. 윈도우의 winget과 같은 역할이고, 맥에는 기본 탑재가 아니라서 먼저 설치합니다. 실행하면 맥 로그인 비밀번호를 묻는데, 입력해도 화면에 글자가 보이지 않는 것이 정상입니다.

02Git 설치·확인

brew install git

git --version

[6] 위 줄로 설치하고 아래 줄로 확인합니다. 버전 번호가 뜨면 정상입니다.

03Node.js 설치·확인

brew install node

node -v
npm -v

[7] node와 npm 두 줄 모두 버전 번호가 나와야 다음 단계로 넘어갑니다.

맥 사용자 확인 맥은 윈도우와 환경 설정이 조금 다릅니다. 진행 중 막히는 부분이 있으면 수업 전에 알려 주세요. 강사님께 미리 공유해 두겠습니다.

8~11단계

클로드 코드 설치와 실행

VS Code를 열고 작업할 폴더를 먼저 지정한 뒤, 그 안에서 터미널을 열어 진행합니다.

08실행 정책 변경 (윈도우만)

Set-ExecutionPolicy RemoteSigned

[8] 윈도우 PowerShell은 기본값이 스크립트 실행 금지라, 설치는 됐는데 실행이 막히는 보안 오류가 납니다. 이 명령은 내 컴퓨터에서 만든 스크립트는 그대로 실행하고, 인터넷에서 받은 스크립트만 서명을 확인하도록 바꿉니다. 관리자 권한 PowerShell에서 한 번만 실행하면 되고, 실행 여부를 묻는 확인창이 뜨면 Y를 입력합니다. 보안 오류가 났을 때 쓰시면 됩니다.

09클로드 코드 설치

npm install -g @anthropic-ai/claude-code

[9] -g는 전역 설치라는 뜻입니다. 이렇게 설치하면 어떤 폴더에서 터미널을 열든 claude 명령을 쓸 수 있습니다. 설치 후에는 claude만 입력해도 실행됩니다.

10중간 확인 없이 실행

claude --dangerously-skip-permissions

[10] 파일을 고치거나 명령을 실행할 때마다 뜨는 확인 절차를 건너뛰고 실행합니다. 작업 속도는 빨라지지만 확인 없이 파일을 바꾸므로, 수업 실습 폴더처럼 지워져도 괜찮은 폴더에서만 쓰세요. 회사 업무 폴더나 중요한 자료가 든 폴더에서는 옵션 없이 claude로 실행하시는 편이 안전합니다.

11파이썬 설치 (윈도우)

winget install Python.Python.3.13

[11] 데이터 처리나 자동화 실습에서 쓰입니다. 맥은 brew install python으로 설치합니다.

12화면을 전체화면으로

"tui": "fullscreen",

[12] 터미널 화면을 전체화면으로 쓰는 설정값으로 수업에서 안내됐습니다. 설정 파일에 넣는 값이며, 넣는 위치는 수업 중 실습으로 다뤄집니다. 필수 항목이 아니니 설치가 끝난 뒤 확인하셔도 됩니다.

VS Code 사용 요령

  • VS Code를 열면 작업할 폴더를 먼저 지정하고 시작합니다.
  • 폴더를 추가해서 함께 작업하는 것도 가능하고, 탐색기에서 폴더를 대화창으로 끌어다 놓아도 됩니다.
  • 작업물이 어떤 구조로 이루어져 있는지 알아 두면 작업이 훨씬 편합니다.

전역 · 프로젝트 · 메모리

설정이 놓이는 세 자리

같은 설정이라도 어디에 두느냐에 따라 적용 범위가 달라집니다. 2회차에서 다룬 내용입니다.

전역 (Global)

  • 위치 ~/.claude/ 아래 settings.json과 CLAUDE.md
  • 적용 범위 어떤 폴더에서 세션을 열든 항상 적용
  • 용도 개인 권한 설정, 키바인딩, 공통 작업 스타일과 선호도 등 "나"에 대한 설정
  • 예 "항상 커밋 메시지는 이렇게 써 줘" 같은 개인 습관

프로젝트 (Project)

  • 위치 해당 폴더 안의 .claude/settings.json과 그 폴더의 CLAUDE.md
  • 적용 범위 그 폴더에서 작업할 때만 적용
  • 용도 빌드 방법, 코딩 규칙, 팀 컨벤션 등 "이 프로젝트"에 대한 설정. Git으로 커밋하면 팀원과 공유됩니다.
  • 예 "이 프로젝트는 npm run test로 테스트한다", "커밋 전 검사 필수"

메모리 (memory)

  • 위치 프로젝트 폴더별로 분리되어 저장됩니다.
  • 적용 범위 한 폴더에서 쌓은 기억은 다른 폴더를 열면 보이지 않고, 그 폴더만의 별도 메모리가 쌓입니다.

정리하면 전역은 "나 자신에 대한 설정", 프로젝트는 "이 작업 폴더에 대한 설정"입니다.

기억을 관리하는 법

메모리 · 파일 · 스킬

작업 품질을 결정하는 요소는 결국 기억입니다. 무엇을 어디에 둘지가 이 수업의 핵심입니다.

메모리가 필요한 이유

  • 일반 작업을 할 때 처음부터 다시 설명하지 않기 위해서입니다.
  • 프로젝트를 수행하면 여러 정보가 쌓입니다. 필요한 정보를 하나로 저장해 두면 필요할 때 가져다 쓸 수 있습니다.
  • 대화할 때 맥락을 유지하려면 메모리에 저장해 두는 편이 유리합니다.

세 가지로 나눠 두기

메모리

절대 까먹으면 안 되는 것. 주요 맥락만 남깁니다.

파일

정보량이 많거나 자주 쓰지 않는 것. 파일로 만들어 두고 필요할 때 참고하게 합니다.

스킬

자주 쓰는 작업. 스킬로 만들어 두고 반복해서 씁니다.
