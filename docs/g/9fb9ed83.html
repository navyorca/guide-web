#부모설득 #학부모 #회사설득

전수 데이터상 "금액을 통보받은 부모가 거부"가 반복된다(정OO·이OO·김지윤). 통보가 아니라 근거를 먼저 준다. 아래 칸을 채워 1장으로 전달한다. 빈칸은 [ ]로 두고 확인 후 채운다.

한눈에 (맨 위 고정)

  • 수강생: [이름] / 목표: [목표 직무·진로]
  • 결론: [최소 구성 N과목·M개월]로 [취업/입시/실무] 준비. 총 [금액]원([할인 근거]).
  • 왜 지금: [프로모션·자리 마감·개강 타이밍 등 사실 근거]. 다음 행동: [결제/재상담] [기한].

1) 이 과정이 필요한 이유 (진로 정합성)

  • 현재 상태: [전공/직무] → [갭: 부족한 실무·툴]
  • 목표 직무: [직무]. 취업 전망 근거: [초봉·연봉·채용 사례 등 실측/사례. 없으면 비워둠]
  • 왜 학원인가: 학교·독학으로 안 되는 [툴·포폴·피드백]을 [기간] 안에 채움.

2) 무엇을·얼마나 (최소 구성)

  • 필수 과목: [과목1·2·3] / 기간: [개월] / 시작: [개강일]
  • 뺀 것: [후순위로 뺀 과목] → 부담 최소화했음을 명시
  • 자격증·포폴: [GTQ/ACP/포트폴리오 등 산출물]

3) 금액 (항목별 투명 공개 → 통보 금지)

  • 원 수강료: [정가] → 할인: [학생/재직/구직 %] + [프로모션 %] + [네이버리뷰 5만] = [최종]
  • 인강(따즈아) 분리결제 시: [금액]원, [기간]권 → 별도 청구 이유([코드 발급]) 명시
  • 결제: [일시불/무이자 N개월/분납]. 개강 1주 전 통보 시 요일·과목·홀딩 조정 가능.

4) 병행·리스크 완화

  • 시간: [저녁반/주말반/비대면 줌]로 [학업/직장] 병행 가능
  • 자습실·인강으로 결석·야근 보완. 개강 후 담당 멘토 1:1 관리.

5) 취업·사후 지원

  • 취업지원팀: 포트폴리오 피드백 · 자소서·이력서 첨삭 · 모의면접 · 블랙기업 필터링
  • 담당 멘토 직접 상담 채널: 오영선 [연락처] → 부모·보호자께서 바로 문의 가능

작성 규칙: 국비 정당성(HRD-Net 미노출 사유 등)은 해당 건만 1줄 추가. 수치는 견적서·실측만, 추정·창작 금지. 개인 건강·가정사 미기재.
