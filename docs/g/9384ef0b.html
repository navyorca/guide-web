스크립트 - 컨텍 대처법

#컨텍대처 #컨텍스크립트 #전화응대 #거절대응 #컨텍흐름

기본 흐름 (이 순서 지키면 대부분 OK)

  1. 본인확인 + 문의 과목 확인
  2. 수강 목적/계기 1~2개만
  3. 가격 먼저 → 시간 확인 → 반 하나 추천
  4. 내방 명분 + 일정 확정

상황별 스크립트

"가격 먼저 알려주세요" / 질문 많다고 할 때

고객이 리다이렉트하면 즉시 따라간다. 탐색 질문은 가격 안내 후로.

"네, 맞아요. 할인 적용 기준으로 20~30만 원대입니다.

평일 저녁이세요, 주말이세요? 그에 따라 딱 맞는 반 찾아드릴게요."

비대면 vs 인강(따즈아) 차이 물어볼 때

한 줄로 끊는다. 추가 설명은 고객이 더 물어볼 때만.

"비대면은 학원 수업을 집에서 줌으로 보시는 거고,

인강은 미리 찍어둔 강의를 언제든 보시는 거예요.

고객님 상황에는 비대면(녹화본) 쪽이 맞겠습니다."

옵션이 너무 많아서 고객이 혼란스러워할 때

선택지 줄이고, 전문가 추천 형식으로 전환.

"제가 말씀드린 게 너무 많았죠. 고객님 상황 정리하면→

저녁 시간 안 되시고, 화목 녹화본으로 보시는 게 제일 무리 없을 것 같아요.

이 방향으로 설명드릴까요?"

"설명이 이해가 안 된다" / "체계가 이상한 것 같다" 할 때

이 타이밍에 설명 더 하면 역효과. 질문 하나로 리셋.

"죄송합니다, 제가 설명이 복잡했네요.

지금 제일 궁금하신 게 [가격인지 / 수업 방식인지 / 시간대인지]→어느 쪽이에요?"

→ 고객이 답하면 그것만 설명. 다른 건 고객이 물어볼 때 추가.

MOS반 vs PPT 디자인반 차이 물어볼 때

"MOS반은 실무 기능 위주라서 보고서 작성하실 때 바로 쓰실 수 있어요.

디자인반은 슬라이드를 예쁘게 꾸미는 쪽에 가깝고요.

보고서 목적이시면 MOS반이 맞습니다."

화목 시간 안 된다고 할 때

"화목이 안 되시는군요.

녹화본 받아서 편하신 시간에 보시는 분들도 많은데,

강사님께 멘토 통해 요청드리면 바로 받으실 수 있어요.

가격은 오프라인이랑 동일하고요."

자주 쓰는 한 줄 정의 (헷갈릴 때 참고)

용어한 줄 설명
비대면학원 수업을 집에서 줌으로 보는 것
인강(따즈아)미리 찍어둔 강의, 시간 제약 없음
녹화본비대면 수업 녹화 파일, 멘토 통해 요청
MOS반자격증 대비 + 실무 기능 중심
PPT 디자인반레이아웃·가독성 등 디자인 특화
멘토수강 시 담당 담임 역할
