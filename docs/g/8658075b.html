1단계 기초 (AI에이전트1)8회
  1. 1회차
    AI 에이전트 이해와 CLI 환경 구축

    AI 에이전트의 개념을 이해하고, 3종 CLI 에이전트(Antigravity, GPT Codex, Claude Code)를 직접 설치하여 동작을 확인한다. 실습: 3종을 모두 설치하고 같은 질문의 응답 차이를 비교한다.

  2. 2회차
    Claude 에이전트 메모리와 파일/폴더 제어

    에이전트에 메모리를 설정하고 이름을 부여하며, 파일과 폴더를 에이전트로 직접 제어한다. CLAUDE.md · /init · /memory · Read/Write/Edit/Bash 도구.

  3. 3회차
    Claude Code 환경 설정과 기본 명령어

    보안 설정, 권한 모드·욜로 모드·모델 선택·주요 명령어를 실습으로 익힌다. settings.json · 웹 Search 도구 · Todos.

  4. 4회차
    세션 관리와 백그라운드 작업

    /resume · /rename · /rewind · /compact · Auto Compact, 백그라운드 프로세스(Ctrl+B), /tasks 작업 목록 관리.

  5. 5회차
    Sub Agent와 Hooks

    Sub Agent 만들기·병렬 실행, Hooks 이벤트 18종, MS Office 365 추가기능 Claude 설치. 실습: Hooks로 위험 명령을 차단하는 설정.

  6. 6회차
    MCP 개념 이해와 실습

    MCP 개념과 설치. Trivago·Canva·Wix·Notion MCP로 숙소 검색·프레젠테이션 내보내기·웹사이트 배포·Notion 페이지 생성.

  7. 7회차
    Skills 활용과 플러그인(Plugin) 실습

    Skills 개념과 사용법, 플러그인 구조·마켓플레이스 설치·관리. 네임스페이스 명령어로 직접 사용.

  8. 8회차
    Claude Desktop 사용법

    Claude Desktop·Cowork·CLI 비교, Agent Teams 협업 구조, GitHub CLI·Antigravity CLI 기반 스킬 제작.

3단계 자동화 (AI에이전트3)8회
  1. 1회차
    자동화의 구조 → 왜 미니 앱인가

    자동화는 수집 → 가공 → 출력 구조의 프로그램 설계. AI가 들어갈 자리와 아닌 자리를 구분. 실습 A 착수: 국세청 API 키 발급, 거래처 200건 조회.

  2. 2회차
    실습 A → 거래처 검증기 완성 (AI 슬롯 0개)

    런타임 AI 없이 완결되는 파이프라인. result.json에서 마크다운 리포트와 엑셀 템플릿 주입 두 출구, 3회 재실행 동일 결과 확인, README.

  3. 3회차
    실습 B ① → 지식베이스 파이프라인

    FAQ·상품정보·상담이력 정규화, 중복 제거·카테고리 부여, knowledge.json 설계, 파일 vs DB 판단.

  4. 4회차
    실습 B ② → 챗봇 런타임과 슬롯 평가

    질문 의도 분류(판단 슬롯) → 지식베이스 조회 → 조회된 것만 근거로 답변(생성 슬롯), 폴백 설계, 25문항 정확도 측정, 3회 반복.

  5. 5회차
    캡스톤 ① → 설계

    내 주제를 수집·가공·출력 3칸으로 분해, AI 슬롯 위치 확정, 설계서 1장 승인.

  6. 6회차
    캡스톤 ② → 수집 + 가공

    재료 수집 경로 확보, 예외 처리, 중간 데이터(json/csv/DB) 누적.

  7. 7회차
    캡스톤 ③ → 출력 + 검증
