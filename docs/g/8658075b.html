    로그인 화면 완성

1단계 기초 (AI에이전트1)8회

  2. 2회차
    Claude 에이전트 메모리와 파일/폴더 제어

    에이전트에 메모리를 설정하고 이름을 부여하며, 파일과 폴더를 에이전트로 직접 제어한다. CLAUDE.md · /init · /memory · Read/Write/Edit/Bash 도구.

  3. 3회차
    Claude Code 환경 설정과 기본 명령어

    보안 설정, 권한 모드·욜로 모드·모델 선택·주요 명령어를 실습으로 익힌다. settings.json · 웹 Search 도구 · Todos.

  4. 4회차
    세션 관리와 백그라운드 작업

    /resume · /rename · /rewind · /compact · Auto Compact, 백그라운드 프로세스(Ctrl+B), /tasks 작업 목록 관리.

  5. 5회차
    서브에이전트 · 훅 · MS 오피스

    서브에이전트에게 일을 나눠 맡기고, 훅으로 Claude 동작에 규칙을 걸고, Excel · Word · PowerPoint 안에서 Claude로 템플릿을 만든다.

  6. 6회차
    MCP · 외부 서비스 연결

    MCP 개념을 이해하고 노션 · 구글 캘린더 · 드라이브 · Gmail · 블렌더를 Claude에 연결해 직접 일을 시킨다.

    스킬 · 라이브러리 · CLI · 플러그인

    라이브러리로 만든 스크립트를 CLI로 바꾸고, 반복 작업을 스킬로 만들어 /명령어로 꺼내 쓴다. 플러그인으로 남이 만든 스킬도 설치한다.

  8. 8회차
    GitHub · Claude 데스크톱 · 클라우드 세션

    작업 폴더를 GitHub 레포로 올려 백업·배포하고, Claude 데스크톱 앱과 웹 클라우드 세션으로 같은 작업을 이어가며 폰에서도 확인한다.

2단계 심화 (AI에이전트2)8회
  1. 1회차
    오피스 스킬과 템플릿 필러

    Claude 공식 오피스 스킬을 설치하고 엑셀·워드 템플릿에 데이터를 넣는 필러 스킬을 만든다. hwpx 스킬로 한글 문서까지 만든다.

  2. 2회차
    Playwright 브라우저 자동화

    Playwright 라이브러리와 Playwright MCP로 Claude가 브라우저를 조작하는 원리를 익히고, 반복 작업을 CLI 스킬로 만들어 네이버 응용까지 실습한다.

  3. 3회차
    GWS CLI로 Google Workspace 자동화

    gcloud와 gws CLI를 설치·인증하고 드라이브 · 캘린더 · 지메일 · 구글 폼 명령을 스킬로 만들어 Claude가 Google Workspace를 직접 다루게 한다.

  4. 4회차
    외부 API로 AI 기능 확장하기

    API와 API 키를 이해하고 네이버 데이터랩 · 타입캐스트 키를 저장한 뒤, CLI 스킬로 음성과 자막을 넣은 쇼츠를 만든다.

  5. 5회차
    Notion DB + API 연결

    DB가 표로 정보를 저장하는 방식을 이해하고, 노션 API와 노션 공식 CLI로 Claude가 노션 DB를 만들고 조회·수정하는 tasks 스킬을 만든다.

  6. 6회차
    세컨드 브레인 → AI 메모 자동 분류

    트리거 키워드 메모를 Claude가 분류해 Notion DB 4종에 자동 저장, 중요도 자동 태깅.

  7. 7회차
    PM 에이전트 → Notion Work DB 자동화

    Work DB 유형 속성(미팅/리서치/문서/이메일)을 읽어 캘린더 등록·데이터랩 조사·시트 생성·이메일 발송을 자동 처리.

  8. 8회차
    하네스 엔지니어링 → 나만의 에이전트 완성

    Notion API · SKILL.md · PM 에이전트를 합쳐 멀티 에이전트 협업 시스템(PM + 5담당자 동시 실행)을 세팅·실행. 캡스톤.
