준비물 클로드 Pro 구독

클로드는 대화하는 AI 서비스입니다. 아래 두 가지를 확인합니다.

  1. claude.ai 계정에 로그인되어 있는지 확인합니다.
  2. 유료 구독(Pro 이상)인지 확인합니다.

클로드 데스크톱(컴퓨터에 설치해 쓰는 클로드 프로그램)의 Code 단추는 유료 구독에서만 보입니다.

보이면 정상: 클로드 데스크톱 왼쪽에 Chat과 Code가 함께 보입니다.

1단계 VS Code 설치

VS Code는 파일을 열어 보고 고치는 프로그램입니다.

  1. 인터넷 창에서 code.visualstudio.com/download를 엽니다.
  2. Windows를 눌러 파일을 받습니다.
  3. 받은 파일을 실행합니다.
  4. 동의에 체크하고 다음을 누릅니다.
  5. "추가 작업 선택" 화면에서 "Code(으)로 열기" 2줄에 체크합니다.
  6. 설치를 누르고 끝날 때까지 기다립니다.

보이면 정상: VS Code 창이 열립니다.

2단계 클로드 데스크톱 설치

  1. claude.ai/download를 열고 Windows 버전을 설치합니다.
  2. 기존 클로드 계정으로 로그인합니다.

보이면 정상: 왼쪽에 Chat과 Code가 보입니다.

Code가 안 보이면 구독 상태부터 확인합니다.

3단계 AI노트 폴더 만들기

폴더는 파일을 담아 두는 칸입니다.

  1. 작업 표시줄의 노란 폴더 아이콘(탐색기)을 엽니다.
  2. 문서로 들어갑니다.
  3. 빈 곳에서 마우스 오른쪽 단추(우클릭)를 누릅니다.
  4. 새로 만들기 → 폴더를 누릅니다.
  5. 이름을 AI노트로 정합니다.
  6. AI노트 폴더 안에서 같은 방법으로 폴더 4개를 만듭니다. 이름은 01_자료, 02_결과물, 03_메모, 04_보관입니다.

보이면 정상: AI노트 안에 폴더 4개가 숫자 순서로 늘어섭니다.

4단계 VS Code로 AI노트 폴더 열기

  1. 탐색기에서 AI노트 폴더를 우클릭합니다.
  2. Code(으)로 열기를 누릅니다.
  3. "작성자를 신뢰합니까" 질문에는 예를 누릅니다.

보이면 정상: VS Code 왼쪽 맨 위에 AI노트가 보이고 그 아래에 폴더 4개가 보입니다.

우클릭 메뉴에 "Code(으)로 열기"가 없으면 VS Code 메뉴에서 파일 → 폴더 열기 → AI노트를 누릅니다.

5단계 아래 칸에서 명령 한 줄 실행

아래 칸은 VS Code 아래쪽에 열리는 입력 창입니다. 터미널이라고도 부릅니다. 글자로 컴퓨터에 일을 시키는 창입니다.

  1. 키보드에서 Ctrl+`를 누릅니다. `는 숫자 1 왼쪽 키입니다.
  2. 아래 칸이 열립니다.
  3. 아래 글을 복사합니다.
Get-Date
  1. 아래 칸에 붙여넣습니다.
  2. Enter를 누릅니다.

보이면 정상: 오늘 날짜가 나옵니다.

아래 칸에서 할 일은 붙여넣기와 Enter가 전부입니다.

6단계 클로드 Code에서 폴더 지정하기

클로드 Code는 내 폴더 안에서 파일을 만들고 고치는 클로드입니다.

  1. 클로드 데스크톱에서 Code를 누릅니다.
  2. 새 세션을 누릅니다. 세션은 대화 한 판입니다.
  3. 폴더 선택에서 AI노트를 고릅니다.
  4. 아래 글을 복사해 입력칸에 붙여넣고 Enter를 누릅니다.
01_자료에 오늘 날짜로 테스트 메모 파일 하나 만들어줘
  1. 허용 창이 뜨면 내용을 읽고 허용을 누릅니다. 허용 창은 클로드가 파일을 만들기 전에 묻는 창입니다.

보이면 정상: 01_자료 안에 메모 파일이 생기고 VS Code 왼쪽 목록에도 나타납니다.

7단계 규칙 파일 CLAUDE.md 만들기

CLAUDE.md는 클로드가 대화를 시작할 때 먼저 읽는 글자 파일입니다. 말투와 저장 위치 같은 규칙을 적어 둡니다.

  1. VS Code 왼쪽 목록 위의 새 파일 아이콘(종이 모양)을 누릅니다.
  2. 이름을 CLAUDE.md로 적습니다. CLAUDE는 대문자입니다.
  3. Enter를 누릅니다.
  4. 아래 글을 복사해 파일 안에 붙여넣습니다.
# 작업 규칙
- 결론부터, 짧게. 인사말 없이
- 새 문서는 01_자료에 만든다
- 모르는 것은 지어내지 말고 [확인 필요]라고 쓴다
- 파일을 지우기 전에 묻는다
  1. Ctrl+S를 눌러 저장합니다.
  2. 클로드에서 새 세션을 엽니다.
  3. "규칙 파일 읽었어?"라고 입력하고 Enter를 누릅니다.

보이면 정상: 클로드가 위 규칙 4줄을 답합니다.

옵시디언(메모 프로그램)은 없어도 됩니다. 수업 실습은 모두 VS Code로 가능합니다. 꾸며진 미리보기가 필요하면 VS Code에서 .md 파일을 누르고 Ctrl+Shift+V를 누릅니다.

  • 클로드가 만든 파일이 VS Code에 안 보임클로드 Code에서 고른 폴더가 AI노트인지 확인합니다.

에이전트란

일반 AI는 한 번 답하고 끝납니다.

에이전트는 입력, 판단, 행동, 결과 확인을 스스로 되풀이합니다. 파일을 만들고 명령을 실행하는 일까지 맡습니다.

그래서 코드를 몰라도 말로 시키면 문제를 정리해서 해결합니다.

작업 폴더를 대화창에 끌어다 놓으면 그 폴더가 지정됩니다.

1단계 Git 설치

Git은 작업 기록을 저장하는 프로그램입니다. 파워셸은 윈도우에 들어 있는 글자 명령 창입니다.

  1. 시작 메뉴에서 PowerShell을 우클릭합니다.
  2. 관리자 권한으로 실행을 누릅니다.
  3. "이 앱이 디바이스를 변경할 수 있게 허용" 창이 뜨면 정상입니다. 예를 누릅니다.
  4. 아래 글을 복사합니다.
winget install Git.Git
  1. 파워셸 창에 붙여넣고 Enter를 누릅니다.

winget은 명령 한 줄로 프로그램을 설치해 주는 윈도우 기본 도구입니다.

보이면 정상: 설치 진행 글자가 나온 뒤 끝납니다.

2단계 Git 설치 확인

  1. 파워셸 창을 닫고 다시 엽니다. 설치 직후에는 새 창이 필요합니다.
  2. 아래 글을 복사합니다.
git --version
  1. 붙여넣고 Enter를 누릅니다.

보이면 정상: 버전 번호가 한 줄 나옵니다.

3단계 Node.js 설치

Node.js는 클로드 코드가 돌아가는 바탕 프로그램입니다.

  1. 아래 글을 복사합니다.
winget install OpenJS.NodeJS
  1. 파워셸 창에 붙여넣고 Enter를 누릅니다.

보이면 정상: 설치가 끝나고 오류 문구가 없습니다.

4단계 Node.js 설치 확인

npm은 Node.js와 함께 설치되는 프로그램 설치 도구입니다.

  1. 파워셸 창을 닫고 다시 엽니다.
  2. 아래 글을 복사합니다.
node -v
npm -v
  1. 붙여넣고 Enter를 누릅니다.

보이면 정상: 두 줄 모두 버전 번호가 나옵니다.

5단계 스크립트 실행 허용 (필요할 때만 1회)

npm 명령에서 "스크립트를 실행할 수 없음" 같은 보안 오류가 뜰 때만 합니다. 오류가 없으면 건너뜁니다.

  1. 관리자 권한 파워셸을 엽니다.
  2. 아래 글을 복사해 붙여넣고 Enter를 누릅니다.
Set-ExecutionPolicy RemoteSigned
  1. 확인 질문이 나오면 Y를 입력하고 Enter를 누릅니다.

보이면 정상: 다시 입력 줄로 돌아옵니다.

6단계 클로드 코드 설치

  1. VS Code로 AI노트 폴더를 엽니다. 방법은 개강 전 준비 4단계입니다.
  2. Ctrl+`로 아래 칸을 엽니다.
  3. 아래 글을 복사합니다.
npm install -g @anthropic-ai/claude-code
  1. 아래 칸에 붙여넣고 Enter를 누릅니다.
  2. 설치가 끝나면 아래 칸에 claude만 입력하고 Enter를 누릅니다.
  3. 로그인 창이 뜨면 claude.ai 계정으로 로그인합니다.

보이면 정상: claude만 입력해도 클로드 코드가 실행됩니다.

이제 실행 방법이 두 가지입니다. 데스크톱의 Code 탭과 VS Code 아래 칸입니다.

7단계 파이썬 설치

파이썬은 프로그램을 짜는 언어입니다. 7~8회차 카드뉴스 실습에서 씁니다.

  1. 아래 글을 복사합니다.
winget install Python.Python.3.13
  1. 파워셸 창에 붙여넣고 Enter를 누릅니다.

보이면 정상: 설치가 끝나고 오류 문구가 없습니다.

8단계 설정을 두는 3곳 알아두기

읽기만 하는 단계입니다.

  • 전역"나"에 대한 설정입니다. 어느 폴더에서 열어도 항상 적용됩니다. 위치는 ~/.claude/ 아래의 settings.json과 CLAUDE.md입니다. ~는 내 계정 폴더를 뜻합니다.
  • 프로젝트"이 작업 폴더"에 대한 설정입니다. 그 폴더에서만 적용됩니다. 위치는 폴더 안 .claude/settings.json과 폴더의 CLAUDE.md입니다.
  • 메모리폴더마다 따로 쌓이는 클로드의 기억입니다. 그 폴더에서만 보입니다.

준비 7단계에서 만든 CLAUDE.md가 프로젝트 자리입니다.

9단계 기억을 두는 3가지 알아두기

읽기만 하는 단계입니다.

  • 절대 잊으면 안 되는 것은 메모리에 담습니다.
  • 양이 많고 자주 안 쓰는 정보는 파일로 만들어 두고 필요할 때 참고합니다.
  • 자주 하는 일은 스킬로 만들어 되풀이해 씁니다. 스킬은 7~8회차에서 직접 만듭니다.

1~2회차에 막히면

아래에서 해결되지 않으면 화면 전체를 사진으로 찍어 담당 멘토에게 보냅니다. 글자가 읽히게 찍어 주세요.

  • 설치 뒤 "인식할 수 없는 명령"파워셸 창을 닫고 새로 엽니다. VS Code 안이면 VS Code를 전부 종료하고 다시 엽니다. 그다음 git --version, node -v를 다시 입력합니다.
  • Node.js 설치가 종료 코드 1603으로 실패관리자 권한 파워셸에서 같은 명령을 다시 실행합니다.
  • node는 되는데 npm만 "스크립트를 실행할 수 없음"5단계를 1회 실행합니다. 권한이 없으면 npm 대신 npm.cmd install -g @anthropic-ai/claude-code를 입력합니다.
  • 로그인했는데 계속 로그인 요구클로드 안에서 /logout을 입력합니다. 창을 닫습니다. claude를 다시 실행하고 다시 로그인합니다.
  • 학원 망에서 설치가 멈추거나 인증서 오류휴대폰 핫스팟으로 다시 시도합니다.
  • 원인을 모르겠음아래 명령을 입력하면 설치 상태를 자동으로 진단합니다. claude doctor

3~4회차 복습

이 날 목표는 두 가지입니다.

  • 설정 파일과 권한으로 클로드의 동작을 정합니다.
  • 대화가 길어졌을 때 관리하는 방법을 익힙니다.

슬래시 명령은 클로드 안에서 /로 시작해 입력하는 명령입니다. 기억나지 않으면 /help를 입력하면 전체 목록이 나옵니다.

1단계 폴더 먼저, 그다음 클로드 시작

  1. 클로드를 쓸 폴더를 먼저 만듭니다.
  2. 그 폴더 안에서 클로드를 시작합니다.
  3. 규칙 파일이 필요하면 클로드 안에서 아래 글을 입력합니다.
/init

보이면 정상: 폴더에 CLAUDE.md가 생깁니다.

폴더마다 따로 두면 프로젝트별로 다른 규칙이 적용됩니다.

2단계 settings.json 3계층 알아두기

settings.json은 클로드의 동작을 정하는 설정 파일입니다. 읽기만 하는 단계입니다.

  • 전역위치는 ~/.claude/settings.json입니다. 모든 프로젝트에 공통으로 적용됩니다.
  • 프로젝트위치는 .claude/settings.json입니다. 이 프로젝트를 쓰는 사람 전원에게 적용됩니다.
  • 로컬위치는 .claude/settings.local.json입니다. 이 컴퓨터에서만 적용됩니다.

순서는 전역, 프로젝트, 로컬입니다. 아래쪽이 위쪽을 덮어씁니다.

주요 항목은 네 가지입니다.

  • model: 기본 모델(클로드의 두뇌 종류)
  • permissions: 허용과 차단 규칙
  • env: 환경 변수(프로그램에 미리 알려 두는 값)
  • hooks: 정해진 순간에 실행할 명령

위치를 지정하지 않고 만들어 달라고 하면 전역에 생성됩니다.

3단계 삭제 차단 규칙 실습

  1. 폴더에서 claude를 실행합니다.
  2. 아래 글을 복사해 입력하고 Enter를 누릅니다.
rm 차단 규칙 추가해줘
  1. 아래 글을 복사해 입력하고 Enter를 누릅니다.
note.txt 삭제해줘

보이면 정상: 삭제 대신 차단 메시지가 뜹니다. settings.json 안에도 방금 만든 규칙이 들어 있습니다.

4단계 권한 모드 바꿔 보기

  1. claude를 실행한 상태에서 Shift+Tab을 누릅니다.
  2. 누를 때마다 모드가 바뀝니다.
  • 일반 모드파일 편집과 명령 실행을 매번 승인합니다.
  • 편집 자동 승인 모드파일 편집은 자동 승인합니다. 터미널 명령은 여전히 승인이 필요합니다.
  • 플랜 모드읽기와 탐색만 하고 계획을 세웁니다. 승인을 받아야 실행합니다.
  • 욜로 모드승인 절차를 전부 생략합니다. 입력은 claude --dangerously-skip-permissions입니다.

보이면 정상: Shift+Tab을 누를 때마다 화면 아래의 모드 표시가 바뀝니다. 플랜 모드에서는 계획만 세우고 파일이 그대로인 것이 정상입니다.

욜로 모드는 권한 확인 자체를 끕니다. 지워져도 되는 실습 폴더에서만 쓰고, 끝나면 평소 모드로 돌아옵니다.

5단계 기본 명령어 익히기

  • /init새 환경에서 CLAUDE.md를 만듭니다.
  • /clear대화를 초기화합니다.
  • /model모델을 바꿉니다.
  • /login과 /logout계정에 로그인하고 로그아웃합니다.
  • /help전체 명령어 목록을 보여 줍니다.
  • /config설정 화면을 엽니다. Status 탭은 버전·계정·모델을 보여 줍니다. Config 탭은 세부 동작을 켜고 끕니다. Usage 탭은 세션과 주간 사용량, 리셋 시각을 보여 줍니다.

종료는 /exit 또는 Ctrl+C입니다. 위쪽 방향키를 누르면 이전 명령이 다시 나옵니다.

보이면 정상: /를 입력하면 명령어 목록이 나옵니다.

6단계 모델과 웹검색

모델은 클로드의 종류입니다. 아래 순서로 빠르고 가볍습니다.

  • Haiku: 가장 빨라서 간단하고 많은 작업에 씁니다.
  • Sonnet: 속도와 성능의 균형이 좋아 기본으로 추천합니다.
  • Opus: 복잡한 작업과 에이전트 코딩의 기본값입니다.
  • Fable: 성능이 가장 높아 가장 어려운 문제에 씁니다.

최신 정보가 필요하면 클로드가 알아서 웹검색을 합니다. 직접 시킬 때는 아래 글을 입력합니다.

오늘 기준 최근 7일 이내에 발행된 AI 에이전트 관련 기사나 글을 웹조사해줘. 각 항목의 주요 내용과 실제 출처 링크도 함께 정리해줘

보이면 정상: 항목별 요약과 출처 링크가 정리되어 나옵니다.

7단계 대화 이어가기와 되돌리기

터미널(아래 칸)에서 시작할 때 쓰는 명령입니다.

  • claude --resume이전 세션을 목록에서 골라 이어갑니다.
  • claude --continue가장 최근 대화를 바로 이어갑니다.

대화 도중에 쓰는 명령입니다.

  • /resume다른 세션으로 바꿉니다.
  • /rename세션 이름을 정합니다. 나중에 찾기 쉽습니다.

실수했을 때 쓰는 명령입니다.

  • /rewind 또는 Esc 두 번: 대화만, 또는 파일 변경까지 되돌립니다.

보이면 정상: /rewind를 입력하면 되돌릴 지점을 고르는 화면이 나옵니다.

8단계 대화 분량(컨텍스트) 관리

컨텍스트는 지금 대화가 채운 분량입니다.

  1. 대화가 길어졌다 싶으면 /context를 입력합니다.
  2. 얼마나 찼는지 봅니다.
  3. 요약해서 이어가려면 /compact를 입력합니다.
  4. 완전히 비우려면 /clear를 입력합니다.

보이면 정상: /context에서 사용량이 그림으로 나옵니다.

계속 지켜야 할 규칙은 CLAUDE.md에 적어 두면 압축 뒤에도 유지됩니다.

Auto Compact는 95% 근처에서 자동으로 압축하는 기능입니다.

9단계 백그라운드 작업

백그라운드는 대화와 따로 뒤에서 일하는 공간입니다. 오래 걸리는 일을 맡겨 두고 다른 일을 할 수 있습니다.

  1. 오래 걸리는 작업이 실행 중일 때 Ctrl+B를 누릅니다.
  2. 진행 상황은 /tasks를 입력해 봅니다.

기본으로 기다리는 시간은 120초이고 넘으면 강제 종료됩니다.

보이면 정상: /tasks 목록에 실행 중인 작업이 보입니다.

3~4회차에 막히면

아래에서 해결되지 않으면 화면 전체를 사진으로 찍어 담당 멘토에게 보냅니다. 글자가 읽히게 찍어 주세요.

  • settings.json을 고쳤는데 반영 안 됨쉼표, 따옴표, 중괄호 하나만 틀려도 파일 전체가 무시됩니다. 저장하고, 클로드를 종료하고, 다시 실행합니다. 그래도 안 되면 claude doctor를 입력합니다.
  • 전역과 프로젝트에서 다르게 동작정상입니다. 아래쪽 계층이 우선합니다. 프로젝트 폴더 .claude 안의 settings.local.json부터 확인합니다.
  • 파일 고칠 때마다 승인 요청Shift+Tab으로 편집 자동 승인 모드로 바꿉니다. 매번 확인하고 싶으면 일반 모드를 유지합니다.
  • 플랜 모드에서 아무것도 안 고침정상입니다. 계획을 승인하고 실행하거나 Shift+Tab으로 모드를 바꿉니다.
  • 명령 이름이 기억 안 남/를 입력하면 목록이 나옵니다. 전체는 /help입니다.
  • --resume 목록에 어제 대화가 없음대화는 폴더별로 저장됩니다. 그때 작업한 폴더에서 실행합니다.
  • 대화가 길어져 앞 지시를 잊음/context로 확인하고 /compact를 입력합니다. 지킬 규칙은 CLAUDE.md에 적어 둡니다.
  • 오래 걸리는 명령이 120초에 끊김실행 중 Ctrl+B로 백그라운드로 넘기고 /tasks로 진행을 봅니다.
  • 클로드가 파일을 잘못 고침Esc를 두 번 누르거나 /rewind를 입력합니다. 되돌릴 지점을 고르고 코드까지 되돌립니다.

맨 위로

5~6회차 복습

이 날 목표는 세 가지를 한 번씩 써 보는 것입니다.

  • 서브 에이전트: 클로드에게 역할을 나눠 맡깁니다.
  • 훅: 정해진 순간에 명령이 자동으로 실행되게 합니다.
  • MCP: 외부 서비스를 클로드와 연결합니다.

1단계 서브 에이전트 알아두기

읽기만 하는 단계입니다.

서브 에이전트는 특정 역할만 맡는 전담 도우미입니다. 별도의 대화 공간에서 혼자 일하고 결과만 원래 대화로 돌려줍니다.

설정 파일은 .claude/agents/ 폴더에 있습니다. /agents 명령으로 목록 보기, 만들기, 고치기를 합니다.

역할 설명이 요청과 맞으면 클로드가 알아서 일을 넘깁니다. 매번 이름을 부르지 않아도 됩니다.

2단계 서브 에이전트 만들기

  1. 폴더에서 claude를 실행합니다.
  2. /agents를 입력합니다.
  3. Create new agent를 고릅니다.
  4. Generate with Claude를 누릅니다.
  5. "보고서 요약 전담 에이전트"라고 역할 설명을 입력합니다.
  6. 저장합니다.

보이면 정상: /agents 목록에 새 에이전트가 표시됩니다.

저장 위치가 사용 범위를 정합니다. ~/.claude/agents/에 저장하면 이 컴퓨터의 모든 프로젝트에서 씁니다. 프로젝트 폴더 안에 저장하면 그 프로젝트에서만 씁니다.

3단계 여러 에이전트 동시에 실행하기

  1. 아래 글을 복사해 입력하고 Enter를 누릅니다.
시장 조사, 데이터 정리, 보고서 초안을 별도 에이전트로 동시에 진행해줘

보이면 정상: 에이전트들이 각각 따로 일하고 결과만 원래 대화에 보고됩니다.

4단계 훅 알아두기

읽기만 하는 단계입니다.

훅은 정해진 순간이 오면 내가 만든 명령이 저절로 실행되는 장치입니다. 예를 들어 도구를 쓰기 직전이나 응답이 끝난 순간입니다. settings.json의 hooks 항목에 등록합니다.

쓰임새는 세 가지입니다.

  • 위험한 명령을 실행 전에 막습니다.
  • 응답이 끝나면 PC로 알려 줍니다.
  • 파일을 고친 뒤 정렬 도구를 자동으로 실행합니다.

훅이 반응하는 순간은 모두 18개입니다. 그중 9개는 진행을 막을 수 있고 9개는 기록과 알림용입니다.

명령이 끝날 때 남기는 숫자가 exit 2면 차단합니다. exit 0이면 계속 진행합니다.

직접 쓰기 어려우면 "위험 명령 차단 훅 추가해줘"라고 클로드에게 시키면 됩니다.

5단계 훅 실습 작업 완료 알림

  1. claude를 실행합니다.
  2. 아래 글을 복사해 입력하고 Enter를 누릅니다.
settings.json에 Stop Hook을 추가해줘. BurntToast 모듈이 설치되어 있는지 먼저 확인하고,
없으면 Install-Module로 설치한 뒤, powershell.exe -NoProfile -Command 형식으로
Import-Module BurntToast 후 New-BurntToastNotification으로 작업 완료 알림을 띄워줘
  1. 아무 질문이나 하나 입력합니다.
  2. 답이 끝날 때까지 기다립니다.

보이면 정상: 응답이 끝나는 순간 PC에 알림이 뜹니다.

6단계 MCP 알아두기

읽기만 하는 단계입니다.

MCP는 AI가 외부 서비스를 직접 다루게 하는 표준 연결 방식입니다. 기기 종류와 상관없이 하나의 규격으로 꽂는 USB-C와 같습니다.

MCP가 없으면 손으로 세 단계를 합니다. 내용 복사, 클로드에 붙여넣기, 결과 다시 입력입니다.

MCP가 있으면 "노션 회의록 정리해줘" 한 마디로 클로드가 직접 처리합니다.

7단계 MCP 등록 실습 트리바고(숙소 검색)

인증 절차가 없어 가장 쉽습니다.

  1. 터미널(아래 칸)을 엽니다. 클로드 안이 아니라 바깥에서 입력하는 명령입니다.
  2. 아래 글을 복사해 붙여넣고 Enter를 누릅니다.
claude mcp add --transport http trivago https://mcp.trivago.com/mcp
  1. claude를 실행합니다.
  2. "강남 지역 1박 2명 숙소를 검색해줘"를 입력합니다.
  3. 이어서 "예산 10만원 이하로 다시 검색해줘"를 입력합니다.

보이면 정상: 숙소 목록에 가격, 위치, 리뷰가 나옵니다. 두 번째 검색에서는 예산에 맞는 숙소로 좁혀집니다.

8단계 MCP 등록 실습 노션(문서 자동화)

  1. 터미널을 엽니다.
  2. 아래 두 줄을 복사해 붙여넣고 Enter를 누릅니다. 등록은 1회만 하면 됩니다.
claude mcp add --transport http notion https://mcp.notion.com/mcp
claude mcp list
  1. claude를 실행합니다.
  2. /mcp를 입력합니다.
  3. notion을 고릅니다.
  4. Authenticate를 누릅니다. 인증은 노션 계정이 맞는지 확인받는 로그인 단계입니다.
  5. 브라우저 인증 페이지에서 URL 신뢰에 체크합니다.
  6. 계속하기를 누르고 로그인합니다.

보이면 정상: /mcp에 notion이 connected(연결됨)로 표시됩니다.

인증도 1회만 하면 다음 세션에서 연결이 유지됩니다.

등록 이름이나 주소를 잘못 넣었으면 claude mcp remove [이름]으로 지우고 다시 등록합니다.

9단계 입력 자리 두 가지 구분하기

읽기만 하는 단계입니다.

  • 채팅창에 입력한 글은 전부 클로드에게 가는 메시지입니다. 컴퓨터 명령으로 실행되지 않습니다.
  • 터미널 패널(아래 칸)은 순수 파워셸입니다. /mcp 같은 슬래시 명령은 claude 안에서만 통합니다.
  • 그러니 먼저 claude를 입력해 실행하고, 그 안에서 입력합니다. 끝낼 때는 /exit입니다.
  • 패널에서 연 claude는 별도 세션입니다. 파일, CLAUDE.md, 훅, 스킬, 메모리는 공유하고 대화 내용만 따로입니다.

5~6회차에 막히면

아래에서 해결되지 않으면 화면 전체를 사진으로 찍어 담당 멘토에게 보냅니다. 글자가 읽히게 찍어 주세요.

  • 만든 에이전트가 안 불림description(역할 설명)이 요청과 맞아야 자동으로 넘깁니다. 역할 설명을 구체적으로 고칩니다. 또는 "report-writer 에이전트로 요약해줘"처럼 이름으로 부릅니다.
  • 다른 프로젝트에서 에이전트가 안 보임프로젝트 폴더에 저장하면 그 프로젝트에서만 보입니다. 모든 프로젝트에서 쓰려면 ~/.claude/agents/에 저장합니다.
  • 알림 훅이 안 뜸settings.json의 쉼표와 따옴표를 확인하고 클로드를 다시 시작합니다. BurntToast 설치 여부는 Get-Module -ListAvailable BurntToast로 봅니다. 결과가 비어 있으면 미설치입니다.
  • 차단 훅이 안 막음exit 2여야 차단됩니다. exit 0은 그대로 진행합니다. PostToolUse 같은 관찰용 순간은 막지 못합니다.
  • /mcp 입력 시 CommandNotFoundException터미널 패널은 파워셸입니다. 슬래시 없이 claude를 먼저 실행하고 그 안에서 /mcp를 입력합니다.
  • claude mcp list가 빈 목록데스크톱 앱의 커넥터는 다른 계통이라 목록과 별개입니다. 목록이 비어 있어도 정상입니다.
  • 등록했는데 서비스가 안 됨/mcp에서 서비스를 고르고 Authenticate를 누른 뒤 브라우저에서 로그인합니다. connected가 떠야 연결이 끝난 것입니다.

맨 위로

7~8회차 복습

마지막 날입니다. 이 날 목표는 세 가지입니다.

  • 자주 시키는 일을 한 줄 명령(스킬)으로 만듭니다.
  • 남이 만든 기능(플러그인)을 설치합니다.
  • 글자 명령(CLI)으로 여러 도구를 연결합니다.

막히면 가장 먼저 VS Code를 다시 시작하세요. 절반 이상이 그것으로 풀립니다.

1단계 스킬 알아두기

읽기만 하는 단계입니다.

스킬은 파일 하나가 슬래시 명령 하나가 되는 기능입니다. 자주 시키는 일을 한 줄 명령으로 줄이는 것이 목적입니다.

  • .claude/skills/<이름>/SKILL.md에 두면 그 프로젝트 폴더에서만 씁니다.
  • ~/.claude/skills/<이름>/SKILL.md에 두면 이 컴퓨터의 모든 프로젝트에서 씁니다.
  • /스킬이름으로 직접 부릅니다. 관련 대화가 나오면 클로드가 자동으로 부르기도 합니다.

자동으로 부를지는 description 한 줄을 보고 판단합니다. 실제로 말할 낱말을 넣어 둡니다. 예를 들어 "회의록, 미팅 메모 정리"입니다.

2단계 카드뉴스 만들기

Pillow는 이미지를 만드는 파이썬 도구 모음입니다. 설치와 코드 작성과 실행은 클로드가 합니다.

  1. 폴더에서 claude를 실행합니다.
  2. 아래 글을 복사해 입력하고 Enter를 누릅니다.
pillow로 1080x1080 카드뉴스 이미지 만들어줘.
배경 남색, 제목 "AI가 바꾸는 세상" 흰색 굵게 중앙,
본문 "2줄 설명" 회색 작게, 하단 로고 영역 포함

보이면 정상: 폴더에 cardnews.py와 output.png가 생깁니다. output.png를 열면 남색 카드가 보입니다.

한글 제목이 깨져 보이면 클로드에게 "한글 폰트로 바꿔줘"라고 요청합니다. Pillow 기본 글꼴은 영문 전용이라, 윈도우의 맑은 고딕(C:\Windows\Fonts\malgun.ttf)을 지정하면 해결됩니다.

pip가 안 되면 python -m pip install pillow로 바꿔 입력합니다. pip은 파이썬 도구를 설치하는 명령입니다.

3단계 카드뉴스를 스킬로 저장하기

  1. 아래 글을 복사해 입력하고 Enter를 누릅니다.
방금 만든 카드뉴스 코드를 /cardnews 스킬로 만들어줘.
배경색, 글자색, 제목, 본문, 사이즈를 인수로 받도록 해줘
  1. 다 만들어지면 아래 글을 복사해 입력합니다.
/cardnews 배경=남색 제목="AI가 바꾸는 세상" 본문="두 줄 설명 텍스트"

보이면 정상: .claude/skills/cardnews/SKILL.md와 cardnews.py 두 파일이 생깁니다. 한 줄 호출로 같은 카드가 다시 만들어집니다.

4단계 플러그인 설치 실습

스킬은 내가 만드는 것입니다. 플러그인은 남이 만든 스킬, 명령어, 에이전트, 훅, MCP를 묶어 설치해 쓰는 것입니다.

설치한 플러그인의 스킬은 플러그인이름:스킬이름처럼 콜론을 붙여 부릅니다.

  1. commit 기능은 Git 저장소 안에서만 동작합니다. 저장소는 Git이 기록을 관리하는 폴더입니다.
  2. 실습 폴더에서 클로드에게 "이 폴더를 git 저장소로 만들어줘"라고 요청해 둡니다.
  3. claude 안에서 아래 3줄을 한 줄씩 입력합니다.
/plugin install commit-commands@claude-plugins-official
/reload-plugins
/commit-commands:commit

보이면 정상: /plugin을 입력하면 Discover, Installed, Marketplaces, Errors 탭이 보입니다. Installed에 commit-commands가 있습니다.

commit은 지금 상태를 이름 붙여 저장하는 동작입니다. 플러그인을 바꾼 뒤에는 항상 /reload-plugins를 실행합니다.

5단계 클로드 데스크톱의 세 자리 알아두기

읽기만 하는 단계입니다.

  • Chat대화형 채팅과 파일 첨부, 분석을 합니다. Projects로 프로젝트 단위로 관리합니다.
  • Code앱 안의 클로드 코드입니다. 시작은 Code 탭을 누릅니다. claude --resume으로 터미널과 대화 이력을 연결합니다.
  • Cowork폴더를 지정하면 클로드가 직접 읽고 만들고 정리합니다. 여러 단계 작업은 스스로 계획하고 실행 전에 승인을 요청하며 끝나면 보고합니다.

개발과 자동화는 CLI, 시각 작업이나 비개발자는 데스크톱이 기준입니다. 둘을 함께 써도 됩니다.

6단계 명령어 한 줄 읽는 법

읽기만 하는 단계입니다.

CLI는 글자 명령으로 프로그램을 조작하는 방식입니다. 명령 한 줄은 [도구] [명령] [--옵션] [인수] 순서입니다.

5~6회차에 입력한 명령으로 읽어 봅니다.

claude mcp add --transport http notion https://mcp.notion.com/mcp
  • 도구: claude
  • 명령: mcp add
  • 옵션: --transport http
  • 인수: notion과 주소

이 구조를 알면 처음 보는 명령도 뜻을 짐작할 수 있습니다.

7단계 GitHub CLI 연결 (GitHub 계정이 있을 때)

GitHub는 코드를 올려 두는 웹사이트입니다. gh는 터미널에서 GitHub를 다루는 명령어입니다.

  1. 계정이 없으면 github.com/signup에서 무료로 가입합니다.
  2. 이메일 인증을 합니다.
  3. 아래 글을 복사해 붙여넣고 Enter를 눌러 설치합니다.
winget install GitHub.cli
  1. 새 터미널 창을 엽니다.
  2. 아래 3줄을 한 줄씩 입력합니다.
gh auth login --scopes repo,delete_repo,workflow,gist,read:org,admin:public_key,write:packages
gh auth status
gh repo list
  1. 브라우저 인증을 고르면 터미널에 8자리 코드가 뜹니다.
  2. 그 코드를 github.com 화면에 입력합니다.

보이면 정상: gh repo list에 내 저장소 목록이 표시됩니다.

PAT는 비밀번호 대신 쓰는 인증 문자열입니다. 채팅창, 공유 문서, 블로그에 붙여넣는 순간 유출됩니다. 삭제 권한(delete_repo)은 꼭 필요할 때만 부여합니다.

8단계 Antigravity CLI 설치 (구글 AI, 구 Gemini CLI)

  1. 윈도우 파워셸을 엽니다.
  2. 아래 3줄을 한 줄씩 입력합니다.
irm https://antigravity.google/cli/install.ps1 | iex
agy --version
agy
  1. 첫 실행 때 색상 테마를 고릅니다.
  2. 브라우저에서 구글 계정으로 로그인합니다.
  3. 나온 인증 코드를 터미널에 붙여넣습니다.
  4. -p 모드를 써 봅니다. -p 모드는 답만 출력하는 방식입니다. 아래 글을 복사해 입력합니다.
agy -p "Claude Code와 Antigravity CLI의 차이점을 간단히 설명해줘"

보이면 정상: 답변만 출력됩니다.

9단계 소개 사이트 만들기

구조를 글로 먼저 적게 한 뒤 만들게 하는 순서입니다.

  1. 작업 폴더에서 claude를 실행합니다.
  2. 아래 글을 복사해 입력하고 Enter를 누릅니다.
내 소개 사이트 구조를 structure.md로 먼저 적어 주고, 그걸로 index.html·style.css·script.js를 만들어줘

보이면 정상: structure.md가 먼저 생깁니다. 이어서 index.html, style.css, script.js 3개 파일이 만들어집니다.

이 방식은 3~4회차 플랜 모드(계획을 승인받은 뒤 실행)와 같은 발상입니다.

7~8회차에 막히면

어떤 문제든 오류 문구를 그대로 복사해 상황 한 줄과 함께 클로드에게 보내면 됩니다. 그 전에 아래 순서로 시도하세요.

그래도 해결되지 않으면 화면 전체를 사진으로 찍어 담당 멘토에게 보냅니다. 글자가 읽히게 찍어 주세요.

  • 00번. 무엇이든 이상함VS Code를 전부 종료합니다. Alt+F4로 창을 모두 닫습니다. 다시 열어 같은 폴더에서 claude를 새로 실행합니다. 파일은 그대로이고 대화만 새로 시작됩니다. 이어가려면 claude --continue를 입력합니다. 그래도 같으면 컴퓨터를 다시 시작합니다.
  • claude를 찾을 수 없음터미널 창을 닫고 새로 엽니다. /claude처럼 슬래시를 붙이면 안 됩니다. claude만 입력합니다.
  • 스크립트 실행 차단관리자 권한 파워셸에서 Set-ExecutionPolicy RemoteSigned를 입력합니다. 물음에 A를 입력합니다. 그다음 00번을 합니다.
  • /mcp, /plugin 오류claude를 먼저 실행한 뒤 그 안에서 입력합니다.
  • 클로드가 멈춘 것 같음점이 움직이거나 Thinking이 뜨면 작업 중입니다. 파일이 많으면 1~2분 걸립니다. 중단은 Esc 1회입니다. 완전 종료는 /exit 또는 Ctrl+C 2회입니다.
  • 답이 엉뚱함/context로 사용량을 확인합니다. 그다음 /compact 또는 /clear를 입력합니다.
  • 파일을 잘못 고침Esc를 2회 누르거나 /rewind를 입력합니다.
  • 허락 창이 계속 뜸Shift+Tab으로 편집 자동 승인 모드로 바꿉니다.
  • 파일이 없거나 엉뚱한 곳에 생김VS Code에서 파일 → 폴더 열기로 작업 폴더가 열려 있는지 봅니다. 터미널 줄 맨 앞 경로(파일이 있는 위치)가 그 폴더인지도 봅니다.
  • pip, npm 빨간 글씨오류 문구 전체를 복사해 "이 오류 뭐야, 고쳐줘"로 전달합니다. 학원 망 차단일 수 있으니 다른 망에서도 시도합니다.
  • 터미널 한글이 깨짐터미널에 chcp 65001을 입력한 뒤 다시 봅니다.
  • 로그인 풀림, 한도 안내/login으로 다시 로그인합니다. 한도 안내는 /config의 Usage 탭에서 리셋 시각을 확인합니다. 급하면 /model에서 가벼운 모델로 바꿉니다.
  • MCP 인증 창이 안 열림/mcp에서 서버를 고르고 Authenticate를 다시 누릅니다. 브라우저 팝업 차단을 풀거나, 터미널에 표시된 주소를 복사해 직접 엽니다.

winget

실행 정책
파워셸의 스크립트 실행 허용 규칙입니다. RemoteSigned는 내 PC에서 만든 것은 허용하고 인터넷에서 받은 것은 서명을 확인합니다.
.md
파일 이름 끝 표시입니다. 글자만 든 파일이며 메모장으로도 열립니다.

폴더 맨 위에 두는 글자 파일입니다. 세션마다 클로드가 먼저 읽어서 말투, 저장 위치, 금지 사항을 매번 말하지 않아도 됩니다.
세션
클로드 Code 대화 한 판입니다. 새 세션은 새 대화입니다.
허용 창
클로드가 파일을 읽거나 만들기 전에 묻는 창입니다. 내용을 확인하고 허용을 누릅니다.
전역, 프로젝트, 로컬
설정을 두는 범위입니다. 전역은 모든 폴더 공통, 프로젝트는 그 작업 폴더, 로컬은 이 컴퓨터에서만 적용됩니다.
settings.json
클로드의 특정 동작을 정하는 설정 파일입니다.
슬래시 명령
/로 시작하는 명령입니다. claude를 실행한 뒤 그 안에서만 동작하며 전체 목록은 /help입니다.
컨텍스트
현재 대화가 채운 분량입니다. /context로 확인합니다.
백그라운드
대화와 따로 뒤에서 일하는 작업 공간입니다. 오래 걸리는 일을 맡겨 두고 다른 일을 함께 진행합니다.
서브 에이전트
특정 역할만 맡는 전담 에이전트입니다. 별도 대화 공간에서 일하고 결과만 원래 대화에 전달합니다.
훅, 이벤트, exit
훅은 정해진 순간(이벤트)에 자동 실행되는 내 명령입니다. 끝날 때 남기는 숫자 exit 2는 차단, exit 0은 계속 진행입니다.
MCP
AI가 외부 서비스를 직접 다루는 표준 연결 방식입니다. 노션, 드라이브, 지메일 등을 바로 다룹니다.
Authenticate
/mcp에서 서비스를 고른 뒤 누르는 로그인 단계입니다. 브라우저 인증 화면으로 이어집니다.
스킬, SKILL.md, description
스킬은 자주 시키는 일을 한 줄로 줄인 새 슬래시 명령입니다. SKILL.md는 스킬 지침 파일이고, description은 그 머리말 한 줄로 클로드가 자동으로 부를지 판단하는 근거입니다.
라이브러리, pip
라이브러리는 남이 만든 기능 모음이고, pip은 파이썬 라이브러리 설치 명령입니다.
Pillow
파이썬 이미지 처리 라이브러리입니다. 카드뉴스 실습에 씁니다.
플러그인, 마켓플레이스, 네임스페이스
플러그인은 스킬, 명령어, 에이전트, 훅, MCP를 묶어 설치하는 단위입니다. 마켓플레이스는 플러그인 목록이고, 네임스페이스는 부를 때 콜론 앞에 붙는 플러그인 이름입니다.
commit
Git에서 지금 상태를 이름 붙여 저장하는 동작입니다.
CLI
글자 명령으로 프로그램을 조작하는 방식입니다. [도구] [명령] [--옵션] [인수] 순서입니다.
gh, PAT
gh는 터미널에서 GitHub 저장소를 다루는 명령어입니다. PAT는 비밀번호 대신 쓰는 인증 문자열이며 절대 공유하면 안 됩니다.
-p 모드
답만 출력하는 방식입니다. claude -p와 agy -p에 공통입니다.
